# 首页下拉助手与周视图节点提醒

日期：2026-09-16。根据后续参考图继续调整：下拉自动聚焦顶部输入胶囊，发送时同一外壳立即向下生长，输入行与回复交叉淡变；不增加独立的搜索页面。视觉以用户提供的黑色向玻璃渐变卡片及全屏参考图为准，运动继续使用手写贝塞尔曲线。

## 交互

- 仅周视图支持整个首页下拉，日视图保留原今日助手入口。越拉阻力越大，回弹区域显示“继续下拉使用助手”。跨阈值振动一次，松开打开顶部助手输入胶囊。移动的整页按系统提供的机身圆角裁切。
- 课程列表必须先滚到顶部，首页下拉才能触发助手。复用周视图的实际顶部滚动状态，未到顶时整段手势交给课程滚动。先锁定方向，再接管下拉；向上滚动、横向切周、点击、多指和已进入的长按编辑保留现有行为。编辑、复制、其他弹层持有交互时禁用入口。
- 输入胶囊和回复卡距屏幕顶边及手机两侧各 8dp。输入胶囊高度 72dp、圆角 36dp，输入上移到黑色顶区，不另留一整行摄像头空白。首次打开仅显示输入文字与右侧发送箭头，自动聚焦并弹出键盘。发送键在保持文字起点不变的前提下右移 8dp。
- 点击发送立即收起键盘，在同一外壳向下生长时，保留刚提交的输入文字做淡出，回复正文同步淡入；不等待首字返回，先显示实际处理状态。回答按内容增长，最大回答高度为窗口高度的 52%，并受键盘及可用高度约束，达到上限后内部滚动。
- 紧凑回复只呈现本次回答，不重复堆放用户气泡和已完成处理步骤。下拉进入全屏后显示完整共享消息记录、附件及模型选择。正文使用 16sp / 24sp 行距、22dp 两侧留白、14dp 段间距；表格采用淡色交替行，不显示外框和网格线。平板窗口（宽 ≥600dp、高 ≥480dp）的提醒、输入、回复和展开会话均采用居中半屏宽度，展开主要增加高度，内部文字宽度随终态确定。
- 回答区底部显示小横杠，下拉或点击进入全屏，上划达到 24dp 后松开关闭助手；提供等价的辅助功能关闭操作。正文未滚到顶部时保留正文滚动，横杠区域始终支持下拉；输入阶段也可再次下拉进入全屏。
- 中间态没有右上角按钮；全屏右上角仅显示退出全屏图标，视觉尺寸与标准顶栏返回键一致为 42dp、触摸范围 48dp，图标 22dp。使用公共 58dp 顶栏高度和 16dp 侧边距，按返回键位置镜像置右。按钮采样已绘制的黑色助手面板，与 producer 同级后绘制，不直接采样壁纸。返回依次处理附件菜单、键盘、全屏、对话；紧凑页也可点击外部关闭。
- 中间态取消固定的回答最小高度，以正文实测高度通过 220ms 贝塞尔过渡展开。日视图助手对话和全屏助手顶部添加局部渐变模糊，标题/按钮在模糊层上方绘制；不新增整页模糊。全屏空会话的课程摘要去掉“点击卡片和助手对话”等入口提示，保留真实天气提醒。
- 首页顶栏操作、日期返回入口、切周按钮和底部导航登记实际按钮区域；落在按钮上的整段下拉手势不触发助手。课程区域仍按顶部滚动门槛处理；胶囊发送按钮也排除下拉接管。
- 完整输入工具位于全屏窗口底部、键盘上方，顶部不放附件、模型选择等功能。
- 原今日助手的排版、消息与运行任务共用；关闭浮层不清空历史，不另起请求引擎。

## 材质与运动

顶部近黑色连续过渡到底部轻玻璃，首页助手删除彩色轮廓和底部光效；教务岛单独恢复并保留原有反馈特效，不随首页关闭光效。统一玻璃底色 alpha 为 0.12、局部模糊 12dp；输入胶囊底部保留深色薄玻璃，发送时与回复卡较透明的底端连续过渡。输入、回复和全屏都不再触发首页的整页模糊或缩放。完整页面 underlay 是 producer，浮层是后绘制的同级 consumer。

原教务导入灵动岛、自动提醒和首页助手共用 `glass/ui/TopAssistantSurface.kt`。文字先按最终尺寸排好版，外壳通过动态边界裁切揭示，不随外壳宽度逐帧换行。紧凑/全屏切换时重新确定一次目标排版。

输入胶囊外壳与输入前景共用液态交互状态，外壳按压放大量由 3dp 降为 1.5dp，采用 320ms 无过冲曲线 `(0.32, 0, 0.24, 1)`，降低触摸高光强度。通过为 `InteractiveHighlight` 注入贝塞尔时间曲线启用本入口反馈，其他既有控件保留默认配置；观察触摸不抢占编辑、发送和下拉手势。

首页下拉和助手全屏使用公共 `core/ui/interaction/DeviceScreenGeometry.kt` 读取窗口圆角；紧凑输入采用胶囊圆角，回复沿用该圆角向下生长，全屏展开时连续插值到机身圆角。四路动画结束后，全屏切为无圆角、无描边的平面材质，并关闭外层转场裁切；返回时重新启用运动轮廓。首页仅在下拉/回弹位移非零时启用机身圆角裁切，静止时关闭。读取跟随当前窗口 Insets，避免启动或旋转时长期缓存旧值。

不使用 Android 或 Compose 弹簧模拟。手写贝塞尔曲线配合关键帧：

| 阶段 | 参数 |
| --- | --- |
| 展开 | `(0.18, 0.76, 0.20, 1)` |
| 收起 | `(0.34, 0.02, 0.30, 1)` |
| 过冲回落 | `(0.22, 0, 0.28, 1)` |
| 末段收敛 | `(0.20, 0.72, 0.26, 1)` |
| 纵向/横向展开 | 640 / 580 ms |
| 收起 | 460 ms |

初次胶囊/提醒展开在 72% 时刻轻微过冲，91% 时刻轻微回落；横纵向有相位差。全屏展开/返回改用无过冲的 520/420ms 贝塞尔曲线 `(0.20, 0.72, 0.26, 1)`，不再弹跳。收回摄像头时最后一小段轮廓渐隐，弱化 OEM cutout 边缘错位。被打断时从当前数值接续；系统动画时长缩放由 Compose 动画运行时处理。

## 状态栏

普通首页保持显示。顶部助手出现时临时渐隐，关闭时恢复；不申请系统悬浮窗权限。Android 11 及以上通过 Insets 动画控制图标 alpha，旧系统或未取得控制权时采用系统隐藏/显示。仅操作状态栏，不隐藏导航栏或 IME。

首页顶部使用忽略显隐的安全区尺寸，避免状态栏隐藏后内容上跳。用户主动唤出临时系统栏时尊重系统接管，取消和卸载时恢复窗口参数。不同 OEM 的实际效果待设备验证。

教务页灵动岛只要仍显示就保持状态栏隐藏，包括缩回小岛后的状态；退出/卸载时恢复。恢复岛体点击展开、按压膨胀及亮度反馈，按压和回弹使用自定义贝塞尔曲线，继续保留底部横杠上滑收起。

## 自动提醒

重要节点采用当前活动课表的一次有效课程开始，连续多节只按整体 occurrence 提醒：

| 时点 | 内容 |
| --- | --- |
| 开始前 30 分钟 | 目标课程与剩余分钟 |
| 开始前 15 分钟 | 目标课程与剩余分钟 |
| 开始时 | 当前课程与下课倒计时 |

- 卡片从真实顶部 cutout 出现，无 cutout 时使用顶部中间锚点。传入触发提醒的目标课程，正文直接按原今日助手组件的自然高度测量，不再额外固定为 164dp 或放大字号比例，底部增加 24dp 小横杠操作区。
- 完整展开后默认停留约 6 秒，服从辅助功能推荐时长；触摸/下拉暂停，松开重新计时。点击或下拉直接进入共享会话的全屏模式，也可返回或通过辅助功能操作关闭。
- 只在前台周视图且没有冲突交互时展示。不抢焦点、不自动请求 AI。离开周视图关闭提醒，进入后台重置提醒；聊天中不覆盖正文。
- 采用实际今天/明天，不随用户浏览周偏移。按下一事件时间调度，恢复前台、课程变化、系统时间/时区变化、午夜时重算。
- 迟到不足 60 秒仍可显示，过期阶段丢弃。同一时间多个事件优先开始时、前 15 分钟、前 30 分钟，同批合并消费。
- 去重身份包含课表、课程、occurrence 日期、开始时间和阶段。改名不重复，改期建立新事件。本地短期去重记录不进入备份。
- 沿用今日助手总开关和首次启用确认，不新增后台定时 Service。

## 文件与共享业务

首页卡片、全屏和日视图共用 `DayAgentConversationDialog`、`scheduleId + date` 消息与后台协调器。保留流式回复、停止、模型选择、图片、操作预演和确认执行。

附件菜单新增“导入课表文件”。选择后交给现有导入界面：ICS 本地解析；其他文件按既有文字提取、PDF 处理、模型能力判断与发送确认进入 AI 解析。继续采用 AI → ImportDraft → 本地校验 → 预览 → 用户确认 → 数据库，不增加静默写库入口。
