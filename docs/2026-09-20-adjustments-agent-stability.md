# 调休、壁纸与 Agent 链路修复记录

本轮在现有未提交的 Agent 改动上继续完成，交付为 GitHub 渠道签名 Release APK；不安装、不发布。版本保持 `1.2.6_beta6` / `33`，Room 保持 `41`。

## 调休

- 自动匹配后的日期选择器返回 `yyyy.MM.dd`，预览用只接受 ISO 日期的 `LocalDate.parse`，因此手动改日期会抛异常。选择器边界统一转换为 ISO，预览使用项目日期解析函数。
- 编辑可修改调休目标日期、原课程日期和停课状态，保留节日标签；移动到已有安排的日期会提示冲突。新增、编辑、自动合并统一做完整列表校验。
- 复用公共 Picker，日期在同一弹窗内切换页面，关闭时保留内容直到退出动画完成。页面底部使用与通知测试按钮相同的悬浮保存入口，并预留滚动内容与安全区空间。
- 日视图原来把“没有调休记录”也判断成停课，已修正。日/周视图点击调休卡片直接打开真正的原课程编辑器，保留点击卡片的实际位置作为开合动画锚点，避免把虚拟显示的日期、星期写回原课程。
- 首页返回只更新指定课表的调休字段，并校验开始编辑时的旧值；不会用旧配置覆盖其他设置，也不会在切换课表后写错课表。

数据库仍使用 `scheduleAdjustmentsJson`，保留 `{date, sourceDate?, label}` 格式：没有 `sourceDate` 表示停课，有值表示引用原教学日，不复制课程、不递归跟随其他调休。原有 BackupFormatV1 与已发布导入格式不变，本轮无 schema 迁移、无清库。

## 壁纸

- 外部或临时 `file:` 图片先复制到应用管理目录，只有已在管理目录中的文件可直接复用。
- 保存失败时保留编辑页面并提示重试，不再把临时 URI 当作保存成功。
- 恢复后私有存储路径前缀变化时，按管理目录文件名解析现有图片；清理同样识别这种引用。
- 清理只处理未引用且超过 24 小时的文件，避免新图片等待配置保存时被提前删除。

这些修复保护仍存在的图片及后续保存，不能恢复已被删除的原始图片。没有使用真实用户备份或设备数据进行升级实验。

## Agent 链路

1. 发送前读取数据库快照，事实版本包含全学期课程、配置与偏好、节次、作息方案、课表列表、日期和天气。
2. 工具可组合读取；独立事实同轮请求，依赖事实后续补读。成功快照收窄后续工具列表，失败读取不进入缓存。
3. 连续追问复用最多五分钟的同版本成功事实，当前状态概览在分钟变化时失效。缓存有数量和字符上限，记忆写入不缓存。事实够用时直接完成当前模型请求，省去额外回答轮次。
4. 操作协议与解析一致，支持根级 `clearFields`，JSON 示例不含多余反斜线。无效参数、缺失整表、重叠修改会拒绝整份计划，不执行其中一部分。
5. `SELECTED_WEEKS` 分开表示原周与目标周。同一门课不同原周可分别修改；移到另一奇偶周时不会因继承限制而消失。延长学期和移动到新增周、改变节次和迁移课程可组合。
6. 相邻课程与设置进入同一事务，预演和执行共用周次规则。回读比较完整课程内容和有效周次，避免片段合并改变 ID 后误判失败。回滚、撤销检查本次提交的状态，防止覆盖之后的新修改。
7. 页面导航、导入和课表管理按顺序交接，失败停止后续步骤并保留已完成步骤的结果。切换课表会使原上下文失效，必须重新读取目标课表；不能用旧课程 ID 修改新课表。
8. AI 导入与对话共用 HTTP/SSE 基础传输；业务解析继续保留各自协议。自然语言 `OPEN_IMPORT` 携带文本或本轮本地图片进入原导入入口，保持 ImportDraft → 本地校验 → 预览 → 确认 → 数据库。

### 能力覆盖

| 能力 | 当前执行方式 |
| --- | --- |
| 增删改课程、指定周次、交换/拆分/合并 | 通用课程动作组合，预览确认后事务执行 |
| 调休、节次与作息、总周数及开学日期 | 设置与结构化动作，可组合课程迁移 |
| 外观、提醒、应用图标、助手偏好 | `GET_SETTINGS` 中实际登记的设置键 |
| 新建、切换、删除课表 | 课表动作；回读验证，保留最后一个课表 |
| 文本/图片导入 | 自然语言交接现有导入、校验及预览 |
| 文件选择、备份恢复、教务登录、API 凭据、系统权限 | 打开原功能页面，由用户完成必要交互 |

不宣称助手可静默控制全部 App 功能；缓存减少的请求轮次可由代码确认，实际 token/端到端耗时仍依赖供应商，未进行在线模型计费或性能对照实验。

## 首页回缩

在隐藏系统栏之前固定摄像头 cutout 锚点，整个开合期间复用，避免部分系统进入沉浸状态后 cutout 消失而改用偏上的回退坐标。未安装到设备做视觉确认。

## 后续界面与查询修订

- 按用户对动画的澄清，日/周视图点击调休课程直接进入已有课程编辑器 Morph；移除此前误加的按压回弹与前置说明弹窗。编辑器显示原课程日期、原教学周与调休影响说明，保存继续使用真实课程及原教学周；关闭沿用点击卡片锚点。调休日胶囊文字统一为白色。
- 调休编辑先展示安排详情，停课/补课切换和日期页面切换复用同一选择器。内容淡入淡出并在 260ms 内调整尺寸，标题和底部操作固定；正文可滚动，日期显示为主副两行，补课课程预览收拢显示。
- 首页输入框关闭终点在已冻结的摄像头锚点上加宽 8dp、加高 6dp，中心下移 4dp，并推迟尾段淡出。
- 全屏助手将背景材质覆盖范围与正文阅读宽度分开，过渡期间覆盖整个窗口，稳定后使用父容器全屏尺寸，释放用于过渡的材质布局。
- 对话提示词、工具决策提示词和调休工具描述统一查询语义：询问调休日期读取事实并直接回答，不生成打开设置动作；空结果明确表示当前课表未配置，不能据此推断学校或法定日历安排。

## 底部覆盖与调休外观跟进

- 主 Activity 默认为系统栏预留区域。首页助手会话期间临时启用窗口 edge-to-edge，使全屏材质可覆盖导航栏区域；保留输入框安全区，退出会话后恢复原窗口布局，不隐藏导航栏。
- 自动获取后按整组停课日期和补课日期检查是否已添加，忽略名称差异，保留学校手动修改的补课原日期。完整已添加的组显示“已添加过”，不再加入待确认列表；缺少日期或日期类型改变的组仍可预览。部分已有的组复用保存过的原课程日期。
- “新增调休日”移到安排卡片组首行。滑动删除保留阈值、触感、回弹和确认逻辑，仅在调休页使用留白、浅红渐变、细边与图文按钮。
- 调休页保存、通知页实时活动测试共用微光按钮选项：降低实色填充，复用现有玻璃和柔和的主题色阴影，其他设置按钮使用原样式。
- 停课课程直接使用中性灰色材质与轮廓光，移除覆盖整卡的灰色遮罩；日/周视图右上角显示“停／补”玻璃角标。按最后一次反馈，角标沿用删除角标的外悬位置与胶囊形状，正文恢复原空间；周视图保留顶部绘制余量，避免首行角标被 Pager 裁切。
