# 2026-10-28 周视图时间与特殊课程

用户要求以收束后的 1.2.8 Beta1 为基线建立第一个时间显示修复 PR，并调整特殊课程、日期作息及日期选择弹窗。基线 main `e72643f2`；工作分支 `codex/week-time-display`，实现分为时间/特殊课程 `d2f8b03b`、日期弹窗 `de382cf2`，随后合入 main 的审查修复。

## 结果

- 移除按整学期实际时钟插入额外行的逻辑。9 点开始的基准作息不会再被其他日期 8 点安排撑出一行；自定义、独立及教务不同作息课程均沿用单一网格。完全在网格以外的课程放在邻近边缘区域，用起止标签表达真实时间，不扩张时间轴。
- 自定义时间从卡片正文移除，在卡片上、下沿各保留一处居中标签；为标签保留卡片内部边缘空间，不新增轴行。移除已退役的“隐藏一端或合并到卡片下方”布局和旧测试。
- 课表保持一个基准作息，日期安排是指定日期的例外；独立作息属于单门课程。当前周的时间轴替换为今天实际日期作息，其他周继续显示基准，缺失节次沿用基准。编辑器补充了修改入口说明。
- 特殊课程支持独立、占位、智能显示。占位卡片跨相邻星期合并，正式课程优先；智能判断整周对应时段，存在周四晚课时不会因周一至周三空闲而压缩全周，整周空闲才合并为时间胶囊。每个浏览周分别计算，支持地点、备注和起止周；旧条目保持独立模式。
- 日期作息模板选择由 Popup 改为二级居中弹窗，选中项使用完整胶囊和主题正文字体；删除“上移”“移除”动作，保留清晰的“全部恢复基准作息”入口，确认保存前均为草稿。

## 验证

`compileGithubReleaseKotlin` 通过；最终单 worker、3GB 堆运行 Release 编译与四类定向回归，共 39 项通过：CourseTimeResolverTest 5、TimeSlotCoursesTest 15、WeekPresentationTest 10、WeekTimeSlotGridTest 9，6m05s。覆盖无额外时间行、边缘课程可见、整周智能判断、周次范围、跨星期合并、旧 JSON 默认值、新元数据回读及已有网格编辑坐标。

早期构建遗漏 Arrangement import 已修正；2GB 守护进程内存不足后精确重启本轮进程，改为单 worker；一次 Gradle 测试参数顺序错误也已纠正，未当作代码验证通过。日志保留于本地忽略文件，不入库。

本轮没有安装或发布新包，尚未进行真机视觉验收；时间标签在大字体下的观感、分页压缩、星期跨列卡片及二级弹窗返回层级需设备确认，PR 保持 Draft。不更改 Room、版本、作息源数据或普通课程提醒语义。
