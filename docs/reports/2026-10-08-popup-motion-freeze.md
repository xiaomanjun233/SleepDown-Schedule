# 二级菜单展开节奏与一级冻结

## 依据与修改

用户反馈上一版二级展开生硬、速率不符合录屏，并要求二级展开时一级冻结、选中框改为胶囊。继续在原任务分支修改公共 Miuix Popup 路线，保留同宽面板、父层 95% 缩放及原玻璃材质。

- 重新抽取录屏展开片段，观察到从触发行圆角撑开、前段快速扩展、末段轻收的过程。将展开弹簧从阻尼 0.99 / 响应 0.45s 调为 0.82 / 0.34s；响应是弹簧参数，并非固定动画总时长。
- 原代码先启动时钟再等待二级子布局出现。现在等待二级真实布局放置完成，并在从零展开时提交锚点帧，再启动展开；快速反向仍从当前进度继续，不归零跳变。
- 发现真实 Dropdown 行已使用 8/0dp 外内距，而锚点计算仍用旧 20/12dp。同步真实上下内距，并在二级标题的插值行高内居中内容，避免标题在展开首帧发生纵向跳动。
- 展开轮廓从触发行的圆角起步，不再从直角逐渐长出圆角。
- 一级的冻结覆盖展开、停留和收起，直到二级完全卸载。停止点击、滚动、滑选和无障碍操作；露出的父层边缘也不再响应。二级标题和系统返回仍可返回一级，外部空白仍可关闭整棵菜单。
- 一级移除指针观察器，保留原视觉变换的自然归位，不再响应二级操作时的拖动位置。二级仍由根手势宿主接续悬停滑选。
- 普通 Popup 行的高亮改为随行高变化的完整胶囊，二级标题使用相同半高圆角，保留 8dp 内缩；对话框行保留原样。
