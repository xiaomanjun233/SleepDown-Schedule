# 首页渲染与公共材质重构

## 本轮边界

从开发工作树 `b779dd55` 派生 `codex/home-render-architecture`，保留
`codex/perf-baseline-20261111`。原工作树未提交修改与原开发分支均保留。
实现提交为 `24c887b2`，仅在本地独立分支提交；本轮未推送、安装或启动应用。

用户明确要求从公共采样与两种材质出发重写，包含首页动效、无用实现清理和公共组件。
清缓存场景指系统设置里的“清除缓存”。尽量保持视觉，液态按压反馈保留。
两种模式统一布局时，用户选择以现有凝光弹窗排版、位置为基准。
滑条和开关按用户追加要求保留现行两套实现，不纳入布局合并。

## 已核实的旧实现

- 首页根装配约 4,600 行，混合场景源、采样就绪、过滤参数和业务编排。
- 课程壁纸已做共享模糊，不能把旧版本“每卡整屏模糊”的结论套到当前代码。
  但共享源由原图 producer、预过滤节点、就绪标记和卡片回退共同管理。
  首帧未就绪时卡片可以暂时建立本地滤镜；凝光还会先创建背景适配器。
- 页切换由一个页面动画加六组独立动画组成；周切换另有跟随历史和用于采样的
  两帧挂载刷新、停稳刷新。历史跟随是交互，延迟刷新是源生命周期问题，两者应分开。
- 整页背景曾保留 32 个冻结源模糊档位与 32 个实时源档位，
  开关采用不同阶段曲线。曲线和资源选择相互耦合。
- GlassGroup、GlassOcclusion、GlassViewport 已无生产调用或实际装配，
  对应旧策略测试不能继续当作有效架构维护。
- 公共 Alert、Picker、胶囊按钮存在“材质 renderer 接管整套组件”的模式，
  凝光与液态分别维护布局/窗口/点击分支。旧 ColorOS 私有 renderer 也仍留在源码里，
  但当前 ProvideVisualEffects 没有装配它；死代码不能作为运行时卡顿证据。

## 重构后的职责

```text
组件布局与业务状态 ─── 控件几何、语义、点击、窗口生命周期
          │
          ├── 材质外观 ── 凝光 / 液态：填色、轮廓、阴影、局部按压反馈
          │
          └── 背景句柄 ── 明确的壁纸源或页面 underlay
                            │
                    MaterialBackdrop
                    源录制 → 一次预过滤 → 共用像素层
                            │
                    源到消费者的坐标变换
                            │
                    局部折射 / 局部高光
```

### 源与失效

1. 课程卡片和其浮动副本直接接收同一个预过滤壁纸句柄，不通过全局 ambient
   反查 raw source，也不靠“就绪”切换本地滤镜。
2. MaterialBackdrop 不认识课程、页码、卡片数量或材质模式。源节点是唯一资源 owner：
   先录制原图、准备滤镜，再绘制可见原图。保留一份原图录制与一份共享过滤结果。
3. 像素版本、尺寸、密度变化使原图失效；材质配方变化只重做过滤；
   消费者移动、缩放、旋转只改变坐标映射。卸载释放过滤资源。
4. 课程预模糊暂保留原分辨率与原滤镜参数，以保护视觉。
   不为“最低采样尺寸”新增按卡片数量变化的质量分支。
5. 背景缓存仅作优化，空缓存必须走同一条生产路径；没有持久化缓存就绪前的逐卡重建。

### 课程以外的采样

| 消费者 | 背景源 | 何时更新 | 过滤与运动 |
| --- | --- | --- | --- |
| Dock、工具栏、页内按钮 | 页面中排除消费者的下层内容 | 下层内容或相对位置改变 | 共用源，保留小面积局部材质参数 |
| 普通 Dialog / Picker / 输入弹窗 | 父窗口完整内容 | 窗口有消费者且页面变化时 | 共同窗口宿主；凝光、液态只提供绘制装饰 |
| 弹窗中的下一层弹窗 | 上一层窗口的完整内容 | 上一层内容变化时 | 只向上一层取源，当前窗口不能采样自己 |
| 课程编辑、锚点菜单 Morph | 路线明确选择的场景源或保留画面 | 按该业务转场的活跃 / 冻结状态 | 维持现有交接；共用坐标补偿，不依靠逐卡延时刷新 |
| 整页模糊 | 页面完整画面 | 活跃场景变化或冻结场景重新录制 | 一份清晰画面、一份固定模糊终态，动画只变混合比例 |
| 不透明普通控件 | 无 | 无 | 直接画颜色与内容 |

两个材质可共用同一原始源；只有**同源、同配方且值得复用**的结果才应共享预过滤。
课程卡片满足这一条件。不同窗口、不同内容层级不应合成一个全局源，否则容易采入消费者自身。
动态页面小控件仍有各自局部处理，不能宣称全应用只做一次模糊。

### 动效

页面切换统一进度和速度，卡片错位由该进度计算，打断不重置位置。
周滑动保留与手势绑定的跟随运动，但不再负责材质预热。
页面背景模糊与动画曲线解耦，保留固定模糊终态，运动仅改变混合比例。
模式独有的按压形变和高光属于材质反馈，不复制布局、业务点击或弹窗关闭状态。

### 公共组件

Alert、Picker、输入弹窗以凝光现有布局为公共宿主。窗口、IME、安全区、退场完成、
内容与按钮排列只维护一份；材质通过绘制接口注入。
胶囊按钮共用高度、内边距、内容槽、禁用语义和点击，皮肤只提供装饰与按压反馈。
分段标签共用同一选择轨道和输入会话；液态指示器跟随宿主实际动画位置。
`RefractionShape` 将裁剪轮廓与折射圆角参数分开，避免液态材质为了支持凝光形状而改变外形。
不将所有高光合成整屏纹理：共用程序与背景，局部轮廓保留各自层级和裁剪。

本轮不把真实锚点菜单、课程编辑 Morph、Dock 融合和 Popup 强行替换为普通弹窗。
它们的采样来源与动作交接有独立语义，保留现行路线；这不等于另设一套普通 Dialog 布局。

## 验证与证据限制

验证重点：空缓存第一帧；20 卡片共享过滤；源变化与过滤参数变化分别失效；
动画反向和源/消费者不同变换；释放与重建；公共弹窗开关和草稿保留。
已完成：

- `testGithubDebugUnitTest` 的 19 个定向测试类共 66 项通过（常规入口，未筛除测试源）。
  覆盖共享源、材质配方失效、平移/缩放/旋转像素对齐、资源释放、首页反向、
  按钮/分段状态、弹窗模式切换和草稿、QuickSheet 异步保存与退出，以及 API 26 弹窗。
- 20 个消费者的原图录制与过滤录制各一次。只移动/缩放消费者时，两者增量均为 0；
  改过滤半径只增加过滤录制，改像素版本两者各增加一次，移除节点释放两层过滤资源。
  这些是 CPU 录制与资源所有权计数，不代表 GPU 每帧完全没有工作。
- `scripts/check_architecture.py` 通过：662 个生产文件，0 项违规文件依赖，

  通过 `git apply --check`、实际应用及 43 个运行时源码逐文件比较。
