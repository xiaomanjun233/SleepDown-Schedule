## 修正后的职责

静态课程卡的绘制链路：

```text
壁纸像素 → 页面持有的 WallpaperTexturePyramid（后台生成模糊层级）
                 │
        CourseMaterialSampling（纹理、配方、生命周期）
                 │
        CourseTextureRenderer（同一源到卡片的坐标映射）
                 ├─ 液态：原 Kyant 折射 / 色散公式 + 原填色 / 高光 / 按压
                 ├─ 凝光：原颜色混合 + 轮廓 / 焦散 / 跟手光
                 └─ 纯模糊：同一纹理采样，省略折射
```

### 源、坐标与生命周期

- 静态壁纸只按像素身份准备一次模糊层级；保留原尺寸清晰层，后续层降采样并预模糊。
  模糊半径选择相邻两个层级并插值；亮度、裁剪和卡片位置只更新采样参数。
- 两种材质共享纹理和坐标换算；凝光焦散直接以同一采样 shader 为输入，
  已删除原来单独维护的位图焦散坐标适配和重复 shader。
- 页面拥有采样、折射和轮廓程序；卡片只提供自身几何及配方。
  同尺寸轮廓和焦散复用程序，仍按卡片轮廓分别绘制，避免改变遮挡和层级。
- 冷启动纹理尚未准备时，只使用源拥有的一份共享 GPU 过滤结果。
  不在每张卡片内临时创建模糊。纹理发布后释放共享 GPU 过滤资源。
- Android 12–12L 和动态壁纸预览保留原 GPU 采样路径，旧系统继续现有材质策略。
  没有新增磁盘缓存、就绪重试或按卡片数量改变视觉质量的开关。
- 编辑浮动卡片需要看见壁纸及下方课程，仍采样实时下层内容。
  整张静止课表在编辑期间共用一份离屏结果；浮动卡不会对每个光学采样重复重画整张课表。
- 拖动位置、缩放和跟手光在布局或绘制阶段读取；只有目标星期／节次真的改变时
  才触发对应业务派生状态。移动、缩放互斥、冲突回退和保存交接沿用原逻辑。

### 动效

首轮把六组独立弹簧换成空间偏移，丢失了用户原来的甩尾。现在保留一个时钟，
同时计算页面轨道和六组错峰弹簧，保留原阻尼、刚度及回弹。
反向打断接续每组当前的位置和速度，直到所有轨道结束才交接页面生命周期。

首轮“固定终态模糊＋整段透明度混合”不等同于原来的模糊扩散，已撤回。
现在变化的是真实模糊半径；32 个廉价效果描述符共用一份模糊表面，
不是 32 张缓存图。仅在接近零半径处淡入，开合共用连续曲线。
凝光冻结页面原先在编辑器显示时回到 Auto 合成，导致光学绘制被后续采样重复执行；
修正为冻结期间与液态一样保留离屏结果，稳定后释放临时模糊资源。
