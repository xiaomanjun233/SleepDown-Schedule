# 2026-10-07 首页弹层、设置与调休体验修正

## 本轮范围

延续同日界面优化。用户再次指出：停/补角标和课程不是同一渲染主体，首页加号/三点到中心表单仍卡顿，调整课程的展开排版无法衔接，并要求进一步简化设置、修正调休保存行为、增加捐赠领奖台，以及为公共 Popup 接入首页同类滑动选择和 Kyant 跟手反馈。

## 实现与依据

- `CourseAdjustmentBadge` 原先每个角标单独挂载玻璃采样、模糊和折射。改为卡片绘制列表内的渐变徽标，保留停/补标识和圆角锚点，不再增加独立 Backdrop 消费者。
- 周视图与编辑展开的源卡片共用文字排版；展开请求携带停/补状态，使用一致的底部预留、徽标和停课颜色。地点、课程名、教师改为上下分区分配高度，行高不小于字形尺寸，减少压缩后叠字。
- 首页菜单到中心表单保留 360ms Legacy 开场与 320ms 退场。原 GraphicsLayer 录制仍引用子节点的实时玻璃绘制，因此在准备/关闭交接时将内容一次性转为临时图像，运动中绘制静态像素，停稳后释放并恢复实时内容。保留捕获失败时的原录制层路径，不改变表单输入和保存语义。
- 设置首页图标右移 4dp，标题位置保持。通用设置外观与布局共用一张卡片，保留液态玻璃说明，开关改称“跟随系统”。小组件说明明确关闭后保留图片和取景，滑块标题/数值采用 Miuix 标题/副标题样式，恢复默认使用刷新图标。
- 通知设置改称“自动勿扰”，精简指定说明文字，通知与后台权限按钮合并并排。AI 设置保留一个右侧带刷新图标的连接测试按钮，测试期间禁用重复点击。
- 调休获取按日期类型及补课来源判断重复；完全相同的安排弹出提示，不重复进入确认。保存操作复用仓库现有事务和并发冲突检查，只提交调休字段，成功后更新父设置页该字段的已保存基线，其他草稿保持独立。列表日期采用 MM.DD，标题和副标题复用标准设置行。
- 捐赠致谢移到赞赏码上方，以发布顺序展示前三位领奖台，使用短暂入场和彩纸效果。没有虚构捐赠者或跨币种比较金额，没有持续循环动画。
- 公共 Miuix Popup 保留触发方式、弹簧与揭示动画，新增按住滑动选择、跨行 `TextHandleMove` 反馈及长菜单边缘滚动；背景和原设置行不压暗。级联标题保留原来的返回点击。Kyant `InteractiveHighlight` 与 `liquidButtonVisualTransform` 共用原有实现，观察手势但不消费选择事件，分别作用于裁切内高光与外层形变。
- 本地 Miuix 改动通过第五份补丁 `patches/miuix-popup-slide-feedback.patch` 交付，根 README 和补丁目录说明同步更新。
