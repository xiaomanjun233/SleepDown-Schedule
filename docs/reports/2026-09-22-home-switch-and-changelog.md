# 首页切换、头像裁切与更新日志

日期：2026-09-22。基于普通版 main 的 Beta9，不更新 exp。

## 修改

- 头像裁切的说明和错误提示占满内容宽度并居中；取消、完成共用现有中性液态按钮，按明暗主题使用黑/白字，不改变裁切、保存逻辑。
- 日/周与首页/设置各使用一条可反向的临界阻尼弹簧进度，驱动短距离水平位移、轻微缩放和透明度；同一次切换的标题、正文及背景共享进度。方向适配 RTL，Compose 动画仍受系统动画时长设置控制。
- 两侧内容保留到动画结束，包括“点过去后立刻点回来”的中断情形；运动中不允许点开移动中的课程或设置项，底部切换入口仍可改变目标。结束后移除离开的页面。SaveableStateHolder 保留页面及日/周各自可保存的滚动状态。
- 首页玻璃消费端在绘制阶段观察切换进度，源背景和共用模糊层包含首页/设置背景进度。首页截帧标识增加运动/稳定状态，运动中不冻结旧画面，稳定后重录；共享壁纸模糊保留到首页退出完成。保持单一 Background/Content producer 及原有玻璃材质，没有为两页复制采样域，没有修改第三方 Backdrop 源码。
- 更新日志原先把 42 个版本放在一个带裁切的 LazyColumn item 内；连续展开会扩大单项测量与图层尺寸，所有版本都参与该项布局。本次按版本拆成独立且有稳定 key 的列表项，展开状态改为 rememberSaveable；保留每个版本的内容、顺序和展开动画。
