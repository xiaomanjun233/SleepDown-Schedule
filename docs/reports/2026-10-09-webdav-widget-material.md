## 小组件根因与修复

- 背景开关无响应：`LiquidToggle` 的长期存活拖动对象捕获了加载前的回调，包括当时的禁用状态或旧的小组件类型。改为通过最新回调分发，禁用时停止手势处理。原数据库更新默认配置与已添加实例的实现保留。
- 旧尺寸 API 的最小宽、最小高不一定属于同一方向；改为竖屏最小宽/最大高、横屏最大宽/最小高，Android 12 以上优先使用宿主精确尺寸列表，旧系统提供横竖两套 RemoteViews。
- 4×2 超过两节课时保留两列。容量按可容纳的紧凑行高计算，单独预留分数 DPI 的像素取整空间，防止第二行裁切；标题限制字号并按实际可用宽高缩小。

## 两档共用渲染

- 原生绘制用 20 张卡片复现：壁纸与课程卡片共同平移五次时，仍多录制 30 次采样。`localPositionOf` 的浮点尾差使精确相等的缓存键失效。现在只忽略低于 0.001 像素的数值误差，并与上次实际录制位置比较，真实位移仍会累计触发更新。
- 对照本地保存的 Nexio 渲染实现，无局部 RenderEffect 的共享模糊消费者直接绘制共享层，避免额外的每卡纹理中转。带折射、冻结场景、导出或自定义变换仍走原路径；圆角、染色和装饰顺序不变。
- 密集页面在静止加载阶段就确定普通滑入，不再为每张卡保留无作用的分组平移层；稀疏页面和中途反向的策略保持原语义。
- 公共 Kyant 补丁同步更新，反向 `git apply --check` 通过。

## Nexio 折射跟进

- 用户要求直接对齐 Nexio。2026-10-09 通过 Codex GitHub 插件读取当前 `master`，确认提交为 [`a259d6f45cc7eeb4526113cab48c7b9b19d98fc2`](https://github.com/HaoZai000/NexioSchedule/commit/a259d6f45cc7eeb4526113cab48c7b9b19d98fc2)，版本说明为 v1.6.5beta2。
- [CourseCard](https://github.com/HaoZai000/NexioSchedule/blob/a259d6f45cc7eeb4526113cab48c7b9b19d98fc2/app/src/main/java/com/haooz/chedule/ui/components/CourseCard.kt) 使用 0.48 倍背景与卡片缓冲；共享背景已经模糊时，每卡只添加 lens。[DrawBackdropModifier](https://github.com/HaoZai000/NexioSchedule/blob/a259d6f45cc7eeb4526113cab48c7b9b19d98fc2/app/src/main/java/com/kyant/backdrop/DrawBackdropModifier.kt) 的有折射分支仍是每卡 record + RenderEffect，并按来源版本、相对位置、尺寸复用。圆角在 draw 阶段裁切，普通静止卡不附加 placement layer。
- 此前 SleepDown 已具备上述主链路。本次补齐 [RuntimeShaderCache](https://github.com/HaoZai000/NexioSchedule/blob/a259d6f45cc7eeb4526113cab48c7b9b19d98fc2/app/src/main/java/com/kyant/backdrop/RuntimeShaderCache.kt) 的程序共享：同一效果源码的编译程序被多个消费者复用，每卡立即创建自己的原生 RenderEffect，保留独立 uniform。未调整采样比例、折射强度、高光、轮廓光或圆角。
- 适配既有超级性能生命周期要求：共享表按绘制线程隔离，最后一个消费者释放后移除程序；直接供 Paint 使用的高光 Shader 不共享。缓存键包含源码，避免自定义 shader 的同名不同源码发生串用。Android 效果入口仍使用 [原生 RenderEffect 创建](https://android.googlesource.com/platform/frameworks/base/+/7d59d89f035a/libs/hwui/jni/RenderEffect.cpp)；本次未合并不同卡片的效果参数。
- 另外用 Compose 原生绘制环境隔离复现切页状态传播：20 张卡在一次切走再切回中，组合计数均从 1 增至 5。`plainSlide` 普通 getter 把内部 `running` 状态传给每个 `homeSwitchGroup` 消费者，即使最终样式始终为整页滑入也重组。改为带结构相等策略的派生状态，只有最终样式发生变化才通知卡片，保留超过 10 张卡片、快速反向和圆角语义。
- 初轮新增测试因此前移除的 `WeekPageSamplingScope.cardCount` 参数引用未同步而编译失败，修正测试调用；随后状态传播复现测试按预期失败（每卡 1 → 5）。同轮共享 Shader 与既有材质测试 4 项通过：20 张卡创建 1 份程序并复用 19 次，最后一个消费者退出后释放，再挂载重新创建 1 份。最终完整回归与打包结果在下方追加。
- 修复状态传播后的首轮新测试从每卡 5 次降到 2 次；剩余一次来自测试未等待 `HomeSwitchPane` 的 200 ms 预热、首轮隐藏后重新挂载。补足 300 ms 虚拟时钟预热后，保持“前后计数完全相等”的断言通过：每卡计数均保持 1。原有 53 项加新增这一项共 54 项通过，0 失败、0 错误、0 跳过。该结果证明隔离场景的冗余重组已消除，不等于实机全部卡顿已消失。

## 日视图形变与顶栏跟进

- 日/周视图分别记录自己的顶栏内容覆盖状态，选择页面时重放该页状态；未选中的保留页面不能改变当前顶栏，切课表时重置。补充真实 Compose 状态回归，覆盖周视图滚动 → 日视图 → 后台周视图更新 → 返回周视图 → 切课表。
- 用户进一步明确整个带角标日卡的形变外观都不一致，不能仅修角标。实际日卡使用共享壁纸模糊、默认采样路径及不缓存的行节点，原形变壳通过屏幕包装层和固定半采样重建材质，包装层身份也使共享模糊兼容判定失效。点击记录实际 Backdrop；形变起点使用原输入及日卡采样参数，再交接到完整场景。日卡来源以实际点击记录优先，不从编辑所需的 targetWeek 推断；日卡不带入周网格。
- 角标与日卡原正文共用原卡尺寸和等比缩放，不再独立固定在不断增高的编辑器底部。超级性能档下禁止固定材质 Morph 分配；中心弹窗保持用户要求的既有样式。
