# 导入记忆、材质分级与小组件预览

## 范围

接续 `codex/agent-import-platform-fixes`。用户明确：记忆修改通过提示词要求 AI 谨慎调整，保留修改能力；卡顿场景是从设置返回包含停课、补课的首页周视图。

## 修改

- 首次导入把已启用的助手记忆作为独立、不可信的用户背景数据发送；后续草稿 Agent 也读取同一记忆。格式修复不携带记忆。导入草稿仍只生成待确认课程修改，不自动写入数据库或修改助手记忆。
- 助手记忆工具继续支持修改既有内容。系统和工具提示要求先核对原文、保留未涉及条目、只作有依据的调整，整段重写或清空须来自当前用户明确要求。并发保存校验请求开始时的旧文本，避免覆盖用户后续修改；超过长度上限拒绝保存，避免静默截断。
- 导入往轮的用户消息、摘要、答复和课程交付物直接展开；历史课程逐卡加入 LazyColumn，进入任务及任务完成时滚到最底部。
- 调休查询改为以完整 JSON 为键的最多四份日期索引；修改、清空、恢复旧版本立即切换索引。周视图课程桶仅随课程和教学日期配置更新，外观设置不使其重建；同一原教学周的补课共用按星期分组的课程结果。保留停课占位、补课来源周和单双周语义。
- 通用设置增加设备级“质感 / 性能”，默认质感。性能档关闭课程折射并隐藏个性化中的折射滑块；保留原设置供切回质感时恢复。保留共享模糊背景，以均匀细描边代替课程高光、阴影和轮廓光；渐进模糊使用单次高斯模糊与渐变遮罩，普通玻璃入口停用透镜。
- 今明课程使用独立的双列静态、XML 和 Android 15 动态预览，统一 336 × 168 尺寸；今日预览标题改为今日。应用内 RemoteViews 宿主按类型区分，布局不同时重新 apply。
- Xiaomi / Redmi / POCO 品牌或 Xiaomi 制造商的设备点击添加小组件时显示桌面手动添加说明；其他设备继续原生 pin 请求与系统权限确认流程。
