# 相邻切周、保留登录态与搜索框避让

本轮继续在普通 main 基线的 codex/home-switch-refinement 工作树开发，不修改 exp，不覆盖已发布 Beta9 附件。

## 点击切周与跳周

点击切周和跳转周不再让 Pager 穿过所有中间周。AdjacentWeekJump 把当前周的逻辑 key 临时交换到目标周旁边，目标周 key 和最终位置保持不变；实际只滚动一个页宽，方向由目标周决定。

连续点击时完成当前可见的两页动画，再处理最新目标，中间请求不排成长队。程序切周期间暂停手势分页和手势结果回写，避免旧的 settledPage 覆盖新目标。等待全部甩尾分组到位后再撤销交换；取消时恢复当前可见的逻辑周。只绘制当前参与的两周，回弹不会带出第三周。

保留上一轮弹簧曲线、六组延迟、真实玻璃采样和首页/设置切换时仅绘制当前周的规则。跳周时保留起点周的补充行高度，避免旧周内容提前被裁掉。

## 非自动刷新学校

自动刷新选择器继续共享教务适配索引及缓存，但排除 AI 教务导入。普通教务导入列表仍有 AI 入口。

已审核 API 学校保留读取登录态并校验的流程；其他学校进入同款登录浏览器，主按钮为“保留登录态”。保存会话时不运行学校导入脚本、不写课程表。账户面板显示“登录态已保留”和“打开教务手动刷新”，不提供后台自动刷新周期。

加密档案增加 sessionOnly，缺失时默认为 false，保留已有 API 档案兼容。WorkManager 的调度和执行、直接后台刷新入口均禁止仅保留登录态的档案自动导入。

手动刷新重新打开已保存页面，恢复缺失 Cookie、已有白名单中的网页存储和浏览器模式；已有浏览器 Cookie 优先，避免旧快照覆盖新会话。首次导航等待恢复完成，随后沿用普通教务导入预览与用户确认；没有改变普通导入的目标课表选择语义。学校会话仍受其自身过期策略限制。

登录态继续本地加密，不新增密码读取；用户保存成功后仍交接系统密码填充服务。

## 搜索框键盘避让

原搜索浮层直接加完整 IME 高度，宿主若已被系统缩小或上移会重复避让。学校选择器的根浮层现在记录键盘关闭时与当前的屏幕底边，只补剩余高度；搜索框和字母索引共用这一计算。键盘展开/分离动画仍使用原始 IME 状态。

自动刷新 Activity 在首次布局前设置与教务选择 Activity 相同的 adjustNothing；根浮层仍按实际位置扣除系统已应用的位移。基线不以窗口高度为 remember key，避免 adjustResize 自身清除基线。
