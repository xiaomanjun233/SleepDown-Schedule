# 2026-10-15 导入、助手与跨周编辑修复

本轮接续 WebView 修复 `3fd0d5aa`，仍为本地候选包，不发布或关闭 GitHub issues。

后续追加的个性化分类、原生凝光控件和自动刷新差异核对，以及最新安装记录，见 [后续调整记录](2026-10-15-refresh-review-and-coloros-polish.md)。下文保留首轮验证时的实现与安装基线。

## 导入与导航

- 口令/文件导入的确认界面改为全屏页面，沿用公共详情页材质与导航。新建/覆盖保存期间禁用重复提交；失败在预览页显示原因，保留草稿供重试。
- 预览退出前等待目标课表的数据进入首页。覆盖导入也等待旧课程 ID 被替换，避免只按相同课表 ID 判断就绪。页面退出后原地打开课表快速设置，不再先进入多课表管理。
- 右上角拆分“课表设置”和“多课表管理”；前者原地打开现有半屏设置，后者使用新的层叠课表图标进入管理。长按空白处的入口、管理页标题和原“自定义”按钮同步改名。
- ICS 按事件所有起止时刻切分显示网格，解决不同星期时间重叠导致全局作息校验失败的问题。SleepDown ICS 保留内嵌作息与学期起点；第一门课在第 5 周也不会被重排成第 1 周。
- 外部日历中无法完整处理的规则进入既有 AI 文件确认流程，不自动发送。SleepDown 日历仍直接本地解析。全天事件、跨日事件、缺失结束时间或复杂重复规则不猜造课程时间。
- 共享导入规范化支持不连续、重叠或顺序异常的节次：整理显示网格，同时保存课程原始节次、时间快照和实际时间。解析后的提醒在预览中展示。无法确定的时间仍提供明确原因，不清库、不静默删除课程；Room schema 未变。

## 助手与输入

- 普通助手在尝试提出操作时，使用一次独立的只读语义判断，要求当前用户有明确请求及对应原文。查询、闲聊、愿望、纠正助手理解不构成修改授权；旧提案也不是授权。原生工具和旧正文计划均经过该判断，导入草稿工作区保持已有流程。
- DeepSeek 官方预设更新为 `deepseek-flash`（V4.1 Flash，图片输入）和 `deepseek-v4-pro`（V4 Pro · 0813），旧 Flash 别名迁移到当前模型，保留密钥、推理档位及自定义端点。依据：[官方模型与价格](https://api-docs.deepseek.com/quick_start/pricing/)、[模型列表接口](https://api-docs.deepseek.com/api/list-models/)。
- 检查 OPPO PLJ110（Android 17）的最新短录屏：键盘上升时输入框仍留在底部，到最后才跳起。按用户后续要求，助手与导入输入栏改为复用学校搜索框的根层视口计算：根据实际屏幕底边扣除窗口已经完成的避让，布局阶段读取动画中的键盘高度，不再使用两套补偿规则或额外动画。
- 助手去掉输入栏外的额外 Scaffold；AI 导入输入栏移到 Scaffold 同级，仍在完整页面的录制层内，保留历史与附件转场。导入列表按输入框含键盘安全区的完整占位留白。日卡助手入口也接收完整 IME 窗口动画。实际手感仍需安装后真机复查。

## 个性化与课程状态

- 保留壁纸和课程两块外部分区，移除它们之间多余的分割线。课程设置按尺寸、内容、颜色、材质排列；字体与彩色文字归入“课程卡片内容”，玻璃/高斯/轮廓光与对应强度放在一起。内部分割线与标题、开关行两端对齐。
- 公共卡片渲染层在灰色基础上叠加整体压暗，覆盖文字、高光和材质，适用于普通玻璃、原生凝光和性能模式，不额外创建离屏渲染层。
- 周视图当天已结束的课程同样灰显压暗，结束判定使用实际显示日期和课程完整结束时间，补课与原课程按日期分别判断。日视图隐藏今天已结束的课程，双日布局也应用相同规则；全部结束时显示提示并保留原有明日预告。历史日期、未来课程和无法确定结束时间的课程保留可见。

## 刷新与会话

- 手动教务、AI 页面导入、口令工具和自动刷新复用统一适配器脚本解析及执行包装。远程脚本每次执行重新取回，脚本单独更新无需等索引变化；请求明确禁用缓存并要求重新校验。
- SWU 本地补丁仅匹配已知损坏源码的精确哈希，不覆盖新的上游脚本；HNNU/HNSF 交互校验使用统一隔离执行包装。相关脚本回归已执行。
- localStorage/sessionStorage 恢复限定为同源主框架的一次注入；完成后移除原生脚本句柄和消息监听。已有对应登录字段时保留当前状态，同标签页标记防止移除回调到达前再次注入。后台 cookie 恢复也不覆盖已有同名 cookie。

## 单次移动与性能

- 编辑课程时选择一个目标教学周，可保存“仅本次”；数据库仅移走来源周的那次课程，保留其他周次，冲突按目标周检查。
- 长按移动后，拖至左右边缘停留约 450 ms 切周，继续停留约每 650 ms 再切一周；学期首尾停止。移动手势由稳定的周视图容器接管，原卡片随翻页离开组合后仍继续跟手。目标冲突或取消返回来源周，缩放不触发切周。
- 液态玻璃的超级性能模式关闭左右切周的逐行跟随和相应逐卡图层，使用普通整页滑动。ColorOS 原生材质路径保持原行为。该改动消除了静态确认的额外动画工作，尚无同设备首滑/重复滑动的帧时间对照，不能宣称已确认 #63 的全部掉帧根因。
