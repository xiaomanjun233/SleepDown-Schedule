# 自动勿扰文案与全局范围

日期：2026-10-04。

自动勿扰开关说明改为用户指定的“在上课期间自动打开勿扰模式”。移除“跟随当前课表”说明，分组标为“上课自动安静 · 全局”。

现有 `CourseQuietPreferences` 已使用独立的 `course_quiet_settings` 保存应用全局设置，没有课表 ID。开关由所有课表共用，切换当前课表不会重置；触发时间仍使用应用当前选中的课表。`NotificationScheduler.refreshToday` 在通知开关判断之前执行课程安静调度，因此不依赖某张课表的课程提醒开关。整门课期间（含课内休息）的持续开启和下课恢复逻辑沿用现有实现。

本次未改变时间规则或状态机，不追加无关测试。已随公共作息库修复完成签名 Release 构建（6m25s）并通过 SDK `5038` 覆盖安装至 PLJ110，返回 `Success`。版本为 `1.2.7_beta2` / 34；产物及 SHA-256 见[公共库修复记录](2026-10-04-period-library-origin-and-deduplication.md)。未在设备上切换系统勿扰，实际体验按用户要求由用户验证。
