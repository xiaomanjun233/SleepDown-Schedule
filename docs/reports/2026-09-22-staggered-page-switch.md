# 首页并行切换与分组甩尾

日期：2026-09-22。普通版 main / 1.2.6_beta9 的后续体验调整，不更新 exp。

## 原因与实现

- 用户反馈上一轮的日周、首页/设置切换偏慢并有卡顿，要求参照切周的横向并行页面，并让上方内容先进入、下方内容逐组延迟。
- 上一版对两页同时做透明度、缩放和弹簧平移。此次改为一屏宽的并行横移，移除整页透明度和缩放；这是针对已存在合成路径的调整，没有实机性能数据证明具体瓶颈占比。
- 主体移动 230 ms；按屏幕可见纵向位置分为六档，相邻档延迟 14 ms，最后一档于 300 ms 到位。标题先走，日视图的助手、时间分组与课程，周视图的节次与课程，设置首页各分区使用各自档位。课程文字、玻璃、角标一起移动，不切碎卡片图像。
- 页面先整体平移，各内容组补偿主进度与本组进度之差。动画值只在图层属性和玻璃绘制中读取，不逐帧重组整页。分组使用可见位置，适应已滚动列表、窗口高度和横屏分栏；运动期间固定分组，避免残余惯性滚动造成延迟档位跳变。
- 连续反向切换取消上一目标，从每组当前位置开始反向，不再追加起步延迟。保留两页至最后一组结束，再移除离开的页面；沿用现有 SaveableStateHolder、保存拦截、动画期输入门控和系统动画倍率。
- 玻璃采样标识观察全部六档进度；主轨迹结束后仍跟随尾部 70 ms，稳定后恢复既有缓存。维持原有 Backdrop 采样域与共享模糊，没有修改第三方库。
