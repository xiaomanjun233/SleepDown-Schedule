# 页面先到位、轻回弹与日周切换开销

日期：2026-09-22。基于已发布 Beta9 的 main 提交 `e7c0bd9` 继续改进，不修改已发布附件或 exp。

## 页面运动

- 背景与整页位移独立使用 dampingRatio 0.86、stiffness 700 的弹簧，先加速、再减速到位，保留小幅回弹。内容继续使用原来的 0.74 / 260 弹簧、六组及每组 18 ms 延迟；组内补偿抵消新的父级位移，不改变内容的绝对轨迹。
- 零初速度的解析曲线中，页面约 142 ms 首次达到 95%，第一组内容约 191 ms，最后一组再延后 90 ms；页面过冲约 0.50%，此前约 3.15%。这些是参数计算，不是设备耗时或帧率测量。
- 页面与内容均保留反向切换时的当前位置和速度；系统动画倍率继续控制动画和分组延迟。
- 转场露出的底层在背景 producer 内统一绘制纯黑，实际画面和玻璃采样使用相同底色。
- 圆角改为跟随页面和全部内容组到最近端点的最大距离，使用平滑曲线收尾；不再将过冲进度直接限制到端点而清空圆角。背景、亮度蒙层、内容与顶栏共用圆角，停稳后移除 clip。
- 背景和共享模糊的录制标识包含页面位移、圆角与运动状态，页面先到位后，内容收尾引起的圆角变化仍会更新采样。

## 日周切换

- `HomeReadableText` 在每次坐标变化后读取壁纸像素、按文本分段计算阴影；彩色课程文字也会重采样背景、求对比度并更新颜色动画。横向切换让这些 CPU 计算跟随大量文字逐帧执行。
- 新增只针对文字对比度的暂停范围：切换期间保持当前文字颜色与阴影，继续更新坐标引用；停稳后通过原有 effect 按最终位置重新计算。新进入的文字使用已有可读的默认前景色。实时玻璃坐标和采样没有冻结，滚动与个性化预览仍保留原来的文字处理。
- 根页面的稳定场景录制同样避开日周及首页/设置切换，避免在新页面刚挂载时额外录制整棵内容树；停稳后补录供弹层使用。原有详情快照和弹层冻结规则保留。
