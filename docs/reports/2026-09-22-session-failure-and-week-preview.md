# 保留登录态错误提示与切周表头

## 反馈与证据

用户截图显示福建农林大学教务页面，“保留登录态”按钮返回“连接失败，请检查网络后重试”。截图不包含网址，用户也无法从当前界面查看网址；没有连接的 ADB 设备，因此没有该次失败的堆栈，不能确认其唯一原因。

代码核对确认两处问题：

- EduImportBrowserUi 把按钮抛出的所有异常统一替换成网络失败，包括页面校验、会话读取、加密保存和后续系统服务错误。
- retainSession 在已有合法网页地址时仍强制要求 Cookie 或 API 白名单内的网页存储非空；这会拒绝仅能通过页面地址或 WebView 原生持久化存储恢复的会话。

本地已审计的拾光源 fa7cbc2ea116e5ffd082a9fe8cb7bdf4407a8713 中，FAFU/FAFU.js 说明该校使用经典正方 default2.aspx，并允许课表在 iframe 内。该说明没有证明用户截图中的具体会话机制。本机对公开入口的请求被网络引导页接管，未将其作为学校真实登录行为的证据。

ASP.NET 支持将会话标识放入路径且恢复时必须保留该路径，参见 [Microsoft IsCookieless 文档](https://learn.microsoft.com/en-us/dotnet/api/system.web.sessionstate.httpsessionstate.iscookieless?view=netframework-4.8.1)。此事实用于覆盖已知兼容缺口，不用于声称截图必然由该机制导致。

## 修复

- 仅保留登录态模式允许 Cookie 和 API 网页存储快照为空，仍保存完整教务地址及已有会话信息。继续加密保存，继续走原有可见浏览器手动导入与预览确认，不运行后台课表抓取，也不启用自动刷新。
- 新增明确的旧正方登录入口过滤，空页面、非网页地址和已识别的登录页不能保存。
- 手动保存的进行中提示不再声称正在验证接口；读取存储、读取凭据、本地保存与任务更新各自返回对应阶段提示。
- 未知异常不直接展示原始 message，避免其中包含会话 URL。诊断只记录阶段、异常类型和调用位置。取消继续正常传播。
- 系统密码填充服务的 RuntimeException 不再阻止已成功保存的会话或已解析的导入预览交接；没有读取密码字段。

## 切周调整

- 每组跟随间隔由 24 ms 减为 16 ms，六组最远延迟从 120 ms 减为 80 ms。保留触点附近分组先动、暂停继续追赶、回弹和相邻目标页跳转。
- 无界模式表头使用 Pager.currentPage 预览，越过半页时更新周数和日期，回拖越过中点后恢复。预览独立于 displayWeek，手势结束后才提交实际周，避免预览反向触发程序跳页。
- 程序跳周期间清除手势预览，使用请求的目标周，避免显示临时重排的物理页号。只在跨越半页时更新表头状态，不逐帧重组整个首页。
