# 全 App AI 执行循环、材料与教务工作区

本轮延续 `codex/rescue-import-materials` 的未提交救援工作树；此前已交付的界面修复保留。用户授权尝试统一全 App AI 循环，并追加插嘴、排队、256k 上下文、本地材料、动态拾光脚本、自用适配和已有适配优先；此前打包并上传既有 Drive 目录的授权持续。本轮未获 GitHub 提交／PR／公开发布或手机安装指令。

## 实现

- 参考 Codex 与 DSH 源码，用 Kotlin 实现统一的有界任务循环、步骤／取消事件和调用账本。Chat、Responses、ChatGPT 账号及初次导入共用规则；相同调用 ID 重放已完成结果，参数变化必须用新 ID。独立保留格式修复次数，不把材料读取当作失败修复。
- `AgentMailbox` 接入今日助手后台协调器与导入任务管理器。插嘴在下一次请求前接收；排队基于上一轮最新结果继续。待处理内容可覆盖编辑、撤回；停止或失败暂停队列，保留继续入口。用户补充进入对话记录，后续修订保留这些要求。附件和队列采用输入框外材质胶囊。
- 上下文默认 256k，投影压缩较早已结算工具结果，保留用户消息、近期结果及完整调用配对。压缩后仍超过本轮预算则停止并提示缩小范围，不删除用户要求或重放写入。预算估算与接口实际 usage 分开。
- PDF 优先在设备提取文字，支持分页文字和原页局部渲染；图片保留原始像素、单独压缩概览。Office／日历／结构化文件沿现有本地解析。读取不依赖上传接口，ChatGPT 账号不假定存在 Files API。未引入手机终端。
- `TASK_WORKSPACE` 提供任务相对路径、SHA-256 写入保护、唯一原文编辑和同步 JS 数据转换。JS 转换使用 AndroidX JavaScriptEngine 隔离进程，受执行时间与堆上限约束，没有通用文件或网络访问。临时文件随本轮工作区释放，不承诺跨杀进程恢复。
- `EDU_WORKSPACE` 绑定具体登录教务文档与任务。模型可读取 DOM／已加载资源、查询同源真实接口、读取和执行本机适配，也可写入／编辑标准拾光脚本再运行。脚本用现有 WebView Bridge 的真实 DOM／fetch 与交互接口，输出被捕获为草稿而非直接触发普通导入；模型结合抓取结果复核后提交。页面变化、取消或旧任务回调不能交付给新任务。工具没有固定“先 OCR 后脚本”的模型路线。
- 成功执行且源码哈希未变的脚本可建议保存；用户确认后写入本机私有适配目录。学校列表单列“我的适配 · 本地”，支持打开测试、编辑、删除。脚本使用拾光 `shiguangBridgePromise`／`shiguangBridge` 约定，维护者默认“小漫君”，提示保留复用来源与许可，不自动发布上游。
- AI 教务入口在任何模型请求之前重新读取适配目录。当前 origin 明确匹配官方／自用适配时，提示并直接运行；多个候选先本机选择。不同主机／端口／协议和通用厂商类型不自动视作同校。
- 通过 `TIME_SLOT_COURSES` 局部补丁补齐特殊课程工具，复用领域校验和既有设置预览／确认／事务。按 id 合并，保留未提及字段与其他特殊课程；错误补丁整体拒绝。预览用可读的前后内容。
- 导入状态与总用时独立悬浮于输入区上方，每约十秒与实际 token、平均输出速度、上下文、缓存数据轮换，容器伸缩、文字模糊叠化。历史按钮跟随应用主题，课程预览的连续节次合并展示。

职责与源码来源见 [AI 任务架构](../ai/AGENT_HARNESS.md)，文件与协议说明见 [AI 文件导入](../ai/AI_FILE_IMPORT.md)。临时上游源码均在 D 盘 `tmp/upstream-{codex,dsh}`，未加入仓库。Android Gradle 缓存、临时文件和日志仍在 D 盘。

## 验证记录

两轮 Release Kotlin 编译分别通过（2m03s、2m22s）。首轮整合回归 20 类共 140 项，139 通过，新增的 Bridge 捕获测试因样本缺少拾光必填的 `teacher`／`position` 而失败；已补空字符串，未放宽生产校验。最终整合回归 21 类 142 项通过（3m02s，0 失败／错误／跳过），日志 `tmp/ai-harness-final-regression-20261102.log`。随后本地适配原子写入中断恢复的两项检查和一次正式签名打包通过（7m05s），但该候选未上传。

收尾审查发现仅有 Native 排队回调的 generation 不足以区分同一页面里旧脚本晚到的异步消息，因此追加了贯穿脚本 Bridge → Native 的独立执行标识。生成脚本保留标准 Bridge 调用方式，内部代理给每次调用附加标识；旧调用不能暂存课程或结束新任务。现有 Node 测试直接执行生产 JS 模板，已验证真实 HNSF 适配的学年校验、异步新旧脚本标识、取消／清理与原生回调；POST 桥接及自动刷新登录态脚本检查也通过。追加后正在重建最终候选并重跑 Bridge／存储定向检查，最终签名与上传身份在下方补记。

已执行架构边界检查：621 个生产文件，0 违规依赖，41 条既有环边。没有调用付费模型、真实学校接口或当前 ChatGPT 账号作端到端验收；设备上的脚本执行、键盘布局、材质与触觉仍需实际测试，不将模拟传输／Compose 测试写成实机结论。
