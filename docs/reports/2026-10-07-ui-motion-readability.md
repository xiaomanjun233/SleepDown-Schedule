# 2026-10-07 界面动效与课程文字优化

## 范围与用户选择

- 作息编辑：按钮边移动边变形，课程与课间逐行飞入，时间轴最后淡入。
- 首页切页：壁纸与页面本体不回弹，上层内容保留错峰甩尾。
- 课程卡片：始终保留浅亮同色字，以软阴影增强辨认；无壁纸也允许调整完整透明度。
- 首页菜单：区分到中心表单与到完整页面，不混用运动参数。
- 设置首页：沿用现有分组，移除第二行描述和行间分割线，使用 Compose 现成彩色图标。最终选择为按功能配色。

## 实现依据

1. `PeriodSchemeEditorUi` 原动作只有位置插值，目标尺寸及“编辑 / 完成”标签直接切换。现在测量终点，并在滚动区域外绘制共享按钮，插值真实位置与尺寸；隐藏被交接的原按钮。入场 480ms，卡片以独立局部进度错峰进入，时间轴在最后 15% 淡入。原页面与顶栏使用一致的顶部缩放基点，保存确认与作息数据规则不变。
2. `HomeSwitchMotion` 原页面弹簧阻尼 0.86 仍会过冲；页面改为有界贝塞尔动画，六组内容保留原弹簧。
3. `courseTextColorForPage` 原无壁纸分支直接返回卡片底色，导致字底同色。现在提升同色系文字亮度，并缩小软阴影范围、增强低对比区域的阴影。无壁纸卡片移除 0.86 / 0.92 的不透明度下限；阴影按真实纯色底与当前卡片不透明度合成计算，不需要窗口坐标采样。
4. `HomeMenuDestinationOverlay` 的添加课程与手动导入保留原中心表单曲线；准备阶段录制源菜单并挂载模糊层，运动阶段复用录制内容。清晰内容的转场透明度放到录制层外，避免写入共享缓存后又被模糊副本重复调制。
5. `AnchoredHomeMenuDestinationStyleMorph` 的课程管理与教务页面单独使用 420ms 有界展开，提前完成源菜单内容交接，保留圆角到进入全屏末段；复用模糊特效，缓存页面本身不携带转场透明度和模糊。稳定时解除临时效果。中心表单不使用这些时序参数。
6. 设置首页使用 26dp 的 Compose Rounded 图标，按功能配色，深色主题适当提亮。更新检查 / 下载状态改为行尾状态标签；二级页说明文字不变。
