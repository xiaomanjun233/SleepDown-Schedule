# 2026-10-29 HD 与课程显示调用核对

用户要求检查实际数据有没有调用指定显示方式，不能用导入、保存和导出往返测试替代界面调用审查；随后要求停止设备采集，先从源码修复 HD 卡顿。已停止采集并恢复手机原来的 `user_rotation=0`（自动旋转保持原来的 0），删除本次创建的手机临时 UI XML。以下没有实机帧率改善或 ROM 观感已验收的结论。

## 数据到界面的实际分支

| 数据或场景 | 调用与显示结果 |
| --- | --- |
| 教务单课有另一套实际时间 | 导入保存完整自定义时钟及源节次，不新增单课独立作息引用；`resolveCourseOccurrence` → `projectWeekGrid` → `courseWeekDisplayFragments`，不按“跟随另一套作息”显示。旧引用保留兼容读取，编辑保存时冻结为自定义时间。 |
| 原第 1 节 09:00–09:45，单课实际为 08:20–09:05 | 周视图仍只有原节次网格；`WeekCourseLayout` 调用 `customTimeRangeOrNull`，通过 `WeekCourseTimeLabel` 在卡片上下沿居中显示实际起止，普通课程内容没有再追加这组时钟。用户随后指定手动新建和修改不能早于作息原点，已撤回临时补卡片高度方案，改为选择和保存校验；教务导入与已有课程保留真实时间，未修改时间的名称/地点编辑可保存。特殊课程不受此下限限制。 |
| 当天第 1 节实际时间不同 | `WeekScheduleScreen` 和 `DayScheduleScreen` 都使用 `weekDayTimeline`；当前周当天左轴替换对应时钟，只有异常实际上课时段的数字黄底白字，时间文字保持原色，课间不沿用异常标。次日和其他周恢复。 |
| 日期作息而非单课自定义 | 时钟来自 `resolveTimetable` 的课表组合日期规则；课程没有因此绑定两套作息。发现日视图只取简化周桶，且完整周桶的链式 map 仅覆盖最后的调休分支；已先选出 occurrences，再统一按实际日期投影，使普通日期、停课和调休均进入相同解析，日视图复用完整周桶，防止今天投影被套到下周。停课保留灰色原课程。 |
| 特殊课程独立模式 | `weekTimeSlotGrid` 的 independent 分支在设定节次后保留独立条带，沿用原位置，不压缩普通节次。 |
| 周一至周三晚自习，周四晚上有课；占位或智能 | GRID 使用现有晚间行；SMART 检查整周真实课程区间，周四有课则不压缩。`bandRuns` 排除有实际课程覆盖或停课的列，`timeSlotColumnRuns` 把相邻周一至周三合并成一张特殊卡片，周四仍显示课程。 |
| 同一晚间时段整周都没有课；智能 | SMART 才压缩覆盖的节次为一条胶囊，显示起止；仅指定起止周生效。判断输入是当周已投影的真实课程区间，包含自定义、日期作息和调休，不能只检查晚自习所在的三个星期。没有对应作息行时作为独立条带显示。 |

`WeekScheduleScreen.gridForWeek` 统一创建当周时间网格，再分别提供给时间轴、当前页和相邻页；课程布局不另造时间轴。源课程与投影分开，显示阶段不写回原始节次、周次、作息或数据库。

## HD 修复

- 星期表头已在外层让出侧栏，移除内部重复加的侧栏偏移，使表头和课程网格共用同一内容起点。
- 移除设置 Pane 整体 56dp 下移。Tabbar 发布稳定状态下的真实窗口范围；按实际字号测量详情标题宽度并检查返回控件所在范围，只有与之相交的详情顶栏局部避让，Scaffold 据实际顶栏高度安排列表，左侧设置列表、背景与其他栏不一起下移。展开侧栏、隐藏或销毁时清除遮挡范围。
- 侧栏开合保持外壳原来的尺寸、位移与材质动画，内部展开列表和紧凑标签各按终态尺寸测量，避免逐帧给所有文字和原生行重排；动画材质读数移入独立表面，避免推动整个列表重组。
- HD 日/周翻页与横屏首页切换复用已有冻结采样入口，只在运动期复用本页材质，停稳后恢复当前坐标采样；不新增整屏截图缓存。页面模糊保留 0–10dp 包络，用有界的 0.5dp 效果池复用 native RenderEffect，模糊进度只在 layer 中读取。

## 同轮界面反馈

按节次编辑的每行按压轮廓为胶囊，节数上限取当前作息从起始节次起真正存在的数量，界面显示上限、滚轮与确认校验一致，不能凭空生成第 4 节。特殊课程的时间、星期、节次位置三行各包胶囊；周视图特殊课程长文字滚动不再添加左右矩形裁切，只有外部胶囊轮廓负责裁切。文字不足宽度时保持居中，页面运动和隐藏时暂停。
