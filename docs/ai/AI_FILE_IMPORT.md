# AI 文件导入与服务能力

更新：2026-11-03

## 统一处理顺序

1. SleepDown 导出的 ICS 直接在本地解析；外部 ICS 优先本地解析并按事件时间推导节次。复杂重复规则等无法完整解析时进入 AI 文件确认流程，仅在用户确认后发送日历文字；超过 60,000 字符要求缩小日历范围，不截断事件。导入预览使用全屏页。
2. CSV、TSV、TXT、Markdown、JSON、XML、HTML、XLSX、DOCX、PPTX、ODS 在设备本地提取为文字，只把最多 60,000 字符的提取结果交给当前文本模型。
3. PDF 必须先尝试本地文字提取；提取结果满足课表文本判定时只发送文字。
4. PDF 文字不足时才渲染为有序 JPEG 页面，并且只允许发送给当前明确支持图片的模型。
5. 普通图片保留原始字节，初次请求发送压缩概览；模型按原图坐标请求细节时，从原始像素裁切。应用文件上限为 20 MiB。
6. 默认不依赖上传。无法可靠本地解析的旧二进制格式提示另存为新版格式或 CSV；原生文件仅在用户显式选择 `RESPONSES_FILE` 且模型声明支持时使用，不按服务商或扩展名白名单决定能否读取。ChatGPT 账号不假定存在 Files 上传接口。

PDF 在 Android 35+ 优先使用系统逐页文本解码；没有可读文字时才使用视觉路线。原 PDF 在本轮工作区保留，`READ_IMPORT_MATERIAL` 可分页／分段读取，`VIEW_IMPORT_DETAIL` 可直接渲染原页局部区域（0–1000 坐标）；不反复放大上一张压缩截图。单份 PDF 最多 100 页，细节图长边 1800 像素。旧系统保留既有提取和页面图像路线，不宣称具有系统尚未提供的文字能力。

Office/ODS 解包只读取与正文有关的 XML，并限制 ZIP 条目数、单条目展开大小和总展开大小，防止异常压缩包造成内存膨胀。文件确认前不会发起模型请求。

上传图片与上传文件都支持系统多选。文件每组最多 20 个、合计 40 MiB，单文件仍为 20 MiB；超过上限整组提示，不截取前几个冒充成功。多文件按选择顺序生成目录，本地提取文字和首张概览，初始文字预算共 48,000 字符；未展示内容明确指引模型通过 `READ_IMPORT_MATERIAL(file, page, offset)` 继续读取。`file=0` 读目录，`file=1..N` 选原文件，页码属于该文件；`VIEW_IMPORT_DETAIL` 使用同一文件编号与原页坐标。每份 PDF 的原文件在任务期间保留供逐页核对。普通助手的多图消息、候选编辑／引导、已发历史和备份恢复均保留整组图片与顺序。

## 教务网页的优先路线（2026-11-02）

点击 AI 教务导入先重新加载本机索引（包含仓库更新和自用适配）。当前网页与适配入口的 origin 明确匹配时，提示后直接抓取，不进行模型路由或文本解析；多个候选先在本机选择。不会凭同一厂商、相似校名或父域名套用其他学校脚本。

未找到明确适配时，点击导入直接进入教务工作区，初次请求只提供脱敏地址／标题，不抓取并发送 DOM 全文，不再要求选择文本／截图或再次确认发送。由模型主动使用 `EDU_WORKSPACE` 读取当前文档的 DOM、已加载资源与接口线索，选择同源接口查询、本机适配的列出／读取／执行或任务脚本试运行。接口应来自实际页面或已核实适配，不猜接口或修改教务数据。`TASK_WORKSPACE` 提供有版本哈希的读／写／精确编辑，通用纯数据 JS 在隔离进程执行；教务脚本按标准拾光异步 IIFE 和 Bridge 在当前登录页面执行。两者职责不同，不用 `main(input)` 替代拾光适配协议。

教务工作区不暴露普通“读取材料”捷径；单步 `IMPORT_SCHEDULE` 不能绕过调查。`EduImportEvidence` 记录真实页面读取，以及接口／适配／脚本执行；只有入口信息时提交会收到配对的工具反馈并继续。模型确认没有可用结构化来源时，调用 `PAGE_FALLBACK` 说明依据后可解析实际页面，不固定厂商、接口或调查顺序。网页不再自动滚动批量截图，视觉模型按需 `VIEW_PAGE` 查看当前单个视口并裁切细节，由模型自主 `SCROLL` 指定区域后继续查看。文件／图片导入保留各自既有入口。

轻量探测使用 `PROBE_SCRIPT`，执行任务文件中的异步函数体，可直接使用 `fetch`／`console` 并 return 局部 JSON，需校验最新哈希。提供的 fetch 只允许当前教务同源 GET／POST，沿用网页登录态；不输出凭据，不进行教务写入。结果最多 120000 字符，最多 20 条日志，20 秒后取消；仅当受控 fetch 实际发起请求才记录接口调查。工具超时与普通错误回给模型分析，父任务取消继续向上传播。最终导入仍使用标准拾光脚本生成 ImportDraft，再本地校验、预览并由用户确认写入。没有新引入 harness 框架、命令行或手机文件权限，也没有默认保存所有网页网络请求正文。

教务工作区与页面材料读取器在主线程创建并绑定当时的文档；工具在后台执行，DOM、资源线索与接口查询的 WebView 调用切回主线程。不能在后台重新创建读取器，因为绑定 URL 本身也是 WebView 操作。文档跳转或任务替换后拒绝读取，不把失败记为已调查。

教务 AI 会话通过可拖动、可收起的小窗挂载同一个已登录 WebView，工具读取、同源查询与临时脚本执行都作用在该文档，不另建渲染器或复制登录态。收起仅折叠可见槽，网页保留非零视口；离开会话或 Activity 停止时归还原浏览器容器，源浏览器释放时撤销小窗能力。窗口受当前顶栏、安全区、输入区及键盘剩余范围约束，拖动只在标题栏生效，网页仍可滚动操作。拖动有轻微弹簧跟随，松手按实际手势速度滑行并在边界衰减回弹；收起、退出、窗口或键盘尺寸变化会停止旧运动并收回合法范围，静止后不再逐帧更新。已适配学校的底部导入直接执行已有适配，AI 入口放在“更多浏览器操作”。

教务脚本的 Bridge 输出先生成并校验 `ImportDraft`，回传给模型结合页面结果复核；不会触发普通导入保存。提问沿同一 Bridge 在 AI 页面显示，停止／跳转后旧回调不能进入新任务。成功执行 `RUN_SCRIPT` 且源码哈希未变化时，当前预览下提供“保存当前脚本”，模型也可通过 `OFFER_SAVE` 建议保存。两者复用同一确认框，支持查看原样源码、校对名称和登录入口；确认后仅保存适配，不保存课程。候选绑定执行任务、文件路径和哈希，文件修改立即失效，重新执行成功后才恢复；保存成功禁用重复操作。当前进程内保留已执行源码，任务临时文件清理后仍可确认保存；旧历史没有保存源码的记录不能补造脚本，需重新执行。

自用适配原子写入私有目录的单校仓库 ZIP：`index/root_index.yaml`、`resources/LOCAL_…/adapters.yaml`、原样 `adapter.js` 和 `school_index.pb`，元数据及 v2 索引遵循拾光官方 schema／proto，索引复用现有仓库解析器。旧 JSON 适配继续读取，显式更新写入新包，不清除旧记录或改动 Room。“我的适配 · 本地”独立展示，支持打开测试、编辑与删除，不自动发布上游。登录入口保留正常跳转参数，移除凭据参数、会话标识与 fragment。

识屏仍保留为用户选择的路线；选择“只发送截图”不开放网页 DOM／接口／脚本工具。文本抓取按完整内容块去重，保留空单元格及合并行列，不去重真实课程行。最终导入始终需要用户预览确认。

## 历史详情入口

手动导入页的“最近导入”快捷卡与 AI 历史列表的条目统一打开 `AiImportHistoryDetailActivity`，并共同声明 `AiHistoryToDetail` 锚定路线。详情页只保留一套 `AiEduImportProgressPage` 实现；返回分别落回真实快捷卡或历史行，稳定全屏后释放临时 clip 与离屏合成。不得再在手动导入 Activity 内嵌第二套详情 Overlay。

## 对话式导入（2026-10-08）

首页助理与日视图助理的加号菜单共用“上传文件”入口。菜单先完成收回动画，再打开系统文件选择器；选择文件后先收回助理，再把 URI 交给同一材料确认、提取和预览流程。选择文件本身不发起模型请求或写入课程，不维护第二套日视图文件解析实现。

公开的模型进度和回复按原顺序显示在对话中，连续的执行事件合为“执行步骤”组，运行中的最新组默认展开，完成后默认折叠，并保留用户手动开关。正文使用 16sp 主色，状态使用 13sp 次色，工具／执行文字使用 12sp 等宽弱色；状态标记列与工具文字缩进统一为 24dp，实时状态也经过 Markdown 渲染。国内模型的公开 reasoning 摘要与 GPT 原生摘要共用同一套对话／实时片段组件，不另设走字框，摘要与历史仍保留。完整结果通过本地校验后，在对应回复下保留课表预览和新建／覆盖操作，后续对话接在其下；继承的同一课表不重复追加预览。用户向上阅读时不强制拉回底部。流式输出单独订阅，每秒最多更新十次，避免每个 token 都重组整页。

步骤显示统一按事件来源和完成状态处理：

| 内容 | 显示规则 |
| --- | --- |
| 完整的公开模型进度／摘要 | 按时间顺序保留，使用状态字号和 Markdown；相邻通道上报同一句时保留模型消息一份 |
| 工具调用、本地提取、修复与校验 | 连续事件在原位置归为“执行步骤 · 数量”，使用实际矢量图标与统一缩进；展开行按压范围裁成胶囊 |
| 尚未完成的公开片段 | 只在底部显示尚未进入记录的内容，协议数据、工具参数长度和重复的本地状态不另起一行 |
| 旧历史的摘要／步骤字段 | 仅在对应结构化消息渠道缺失时补充，复用同一消息／步骤组件，不再另设“处理详情”或重复铺开全部摘要 |
| 提问、失败与最终结果 | 待回答问题和错误直接显示；最终回复使用正文字号，校验后的课表预览紧随其后 |

预览移除“课表选项”、阶段切换和手动 JSON 编辑入口；每轮不可变快照仍保留新建／覆盖操作。继续对话基于最新可见结果，旧选择锁定不再隐式影响输入。周次与节次仅合并连续数字区间，例如“第1–4、6–8周”“第1–3、5节”，不填补缺失项，不改变保存数据。

支持原生摘要的接口沿用原生流；没有原生摘要时，提示模型在普通文本里发送独立的 `<import_progress>…</import_progress>` 阶段摘要，随后提交 `IMPORT_SCHEDULE`。完整标记摘要、普通助手公开的完整段落以及显式公开摘要通道的完整段落均进入记录；普通文字在段落结束或消息完成时提交，保留换行及加粗，不再压为 180 字单行。模型报告单条最多 4096 字符，执行记录最多 180 字符；历史仍按既有总预算裁剪。Chat／Responses 的完成事件回放不重复记录，Responses 不同消息和摘要分段独立处理。最终课程 JSON、工具参数、私有思考标签、不透明协议字段及 Responses 原始 reasoning_text 不进入进度。摘要仅报告已确认的信息、当前阶段和待核对项，不由客户端编造进度。仅返回标记摘要的一轮允许续接一次，仍未提交数据则明确报错，不把摘要当作课程 JSON 进入修复。

初次解析提供 `ASK_IMPORT_DETAILS` 工具：材料缺少星期、节次、周次等排课必需信息时，最多提出三个问题并等待用户回答；缺教师、地点不阻止导入。提问优先于同一响应中的推测课表，不写数据库，也不触发格式修复。

解析途中发送的补充先进入独立候选胶囊，默认排队。胶囊内直接提供编辑、删除、引导三个图标；点击引导才在下一步模型请求前加入当前任务，编辑覆盖同一候选并保留消息 id，删除只撤回未处理候选。排队在当前回合结束后基于最新课表继续；本轮末尾到达的引导转为下一轮，不丢弃。停止或失败暂停队列，可通过候选的引导操作继续。附件胶囊居中，候选与附件均在输入框材质之外，并接入柔性反馈；输入框本体不因附件加高。已接收的用户补充进入对话与历史；此保留仅限当前进程，不承诺杀进程后恢复未提交的队列。

共用执行循环、工具调用账本与上下文规则见 [AI 任务架构](AGENT_HARNESS.md)。默认上下文窗口 256k，接近预算时压缩已结算的较早工具结果，保留调用配对、用户要求和最新草稿；仍超出预算则提示缩小任务，不自动删用户要求。信息胶囊只保留一条并居中：手机和平板统一放在输入框上方。用时钟、速度、缓存、上下文环形图标同时显示用时、tok/s、缓存命中率及上下文占用率，不再定时轮播大段文字。输入／输出 token 数保留在可访问性统计中；未知统计显示“—”。容器和数字保留伸缩／模糊叠化，信息胶囊也启用柔性反馈。

窗口达到 840dp 时，导入对话页左侧常驻导入历史，右侧正文与输入区最大 840dp 并居中；点击历史在同一会话组件中恢复，可切回当前导入，后台任务不中断。历史列表只加载摘要，选中后才在 IO 线程加载该会话完整图片；手机保留原历史入口。输入框、附件／候选和底部统计按实际高度给对话预留空间，键盘升起时保持既有跟随底部语义。

统计、附件和候选胶囊退出时保留内容至槽高度收缩结束，依赖该高度的控件与对话留白逐帧移动；候选横向列表按稳定 id 做删除和位置动画，退出项不再接受编辑／删除／引导操作。两端复用同一布局，不能先移除内容再瞬间回收占位。

统计、附件、候选与输入胶囊和“回到最新”按钮共用轻入场：260ms 内由 94% 放大到正常大小，6dp 模糊渐清并淡入。按控件身份播放一次，数值刷新、编辑与引导不重复播放；稳定后撤掉临时图层和模糊资源。Android 31 以下保留缩放／淡入。临时脚本的实际验证步骤见 [本地验证](AI_SCRIPT_SMOKE_TEST.md)。

用户确认导入后才写库；新建与覆盖成功均切到导入课表的周视图，再打开已有快速设置，引导确认开学日期/当前周。保存失败保留可重试的确认入口，不进入成功引导。格式修复仍只处理前一轮 JSON，沿用原服务，最多三次，不重新上传材料。

## 阶段工作区与实时活动（2026-10-10）

手动文件、文本和教务页面继续走同一条材料确认、提取、修复、校验与预览链路。流式片段只显示识别数量；未闭合 JSON、缺必需字段或未通过本地校验的数据不会成为可导入阶段。

- 进行中只保留一处可换行的未完成公开片段，每秒最多更新十次；已进入对话的进度不在状态行重复显示。明确由服务端公开的 Chat reasoning 字段、Responses reasoning summary 和模型阶段摘要可更新片段；实际请求、读取工具、修改和校验通过执行事件显示。客户端不定时编造进度，不挖掘隐藏或加密推理。
- 模型已公开的阶段说明和真实操作事件每轮保留至多 128 条，公开进度与执行组按事件顺序排列；不会将全部工具调用挪到对话末尾，也不与旧步骤列表重复显示。总计时显示“正在导入中”，从本次任务开始累计；收 token、工具往返、状态变化与重新绑定回调均不重置。计时留在实时叶节点，每秒刷新，不伪造百分比或工作结果。
- 完整结果进入课表工作区。初次识别和 Agent 每次成功编辑形成不可变且已校验的阶段，预览固定在对应轮次。任何已显示的阶段都可以走原有新建／覆盖确认入口。旧阶段选择、手动 JSON 编辑的已发布历史数据与兼容 API 保留，当前页面不再暴露相应入口。
- 继续对话使用最新可见课表 JSON，通过现有 Day Agent 的真实任务循环执行 READ_IMPORT_JSON 与 PATCH_IMPORT_JSON。用户 2026-11-01 要求当前会话与历史每轮都携带原图：模型支持图片时，每轮附上全部可用原图一次，保留页面顺序；同轮工具往返沿用这份输入，不向历史消息重复堆叠图片。原始文字一并提供用于核对，原材料不能撤销用户此前的修改；不重新提取文件或 OCR。文本模型仍可按 JSON 继续编辑。补丁携带版本号、原子校验；错误或过期补丁不改变工作区。此作用域不提供设置、记忆、数据库、日历或联网工具。格式修复仍只发送失败 JSON。
- 停止、失败和重新提问保留已校验阶段。任务 ID 隔离旧回调、预览和通知；通知打开时优先恢复相同任务的本地历史。没有历史的已丢失材料需重新选择，不显示另一个任务的课表。

每个会话最多保存 32 个阶段、合计 1 MiB，单个 JSON 最多 256 KiB；达到上限明确提示并保留已有选择，不默默删掉阶段。历史沿用现有保留天数和十条记录上限，文字上下文最多 2 MiB。用户 2026-11-01 明确要求保留历史原图：压缩图片独立保存为应用私有文件，JSON 只写引用，并为引用预留文字预算；列表不加载图片，详情及通知恢复在 IO 线程加载对应记录的原图。图片随所属记录删除、到期和条数淘汰一起清理。备份沿用 V1 已有 `ai_import_screenshot` 资产类型，恢复保留原文件与顺序，不改 Room 或备份版本；旧内联图片仍可读取。已经由旧版本丢弃的原图无法凭文字历史恢复。不保存 API Key 或新的远端文件。
