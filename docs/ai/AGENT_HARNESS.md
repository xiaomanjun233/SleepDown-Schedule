# AI 任务执行架构

实现采用 Kotlin，参考 Codex 与 DeepSeek Harness 的职责划分，没有嵌入 Rust/Node 运行时，也没有移植完整产品。

参考源码固定在本轮调研快照：

- [Codex](https://github.com/openai/codex/tree/3026a8e54e0f48c4d8074cd700f35b0697abc329)：回合边界、工具结果配对与取消。
- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness/tree/ce7073d51254c26cd63b22a60835b8f948deb447)：输入收件箱、请求上下文投影、任务工作区。

## 职责

`core/ai/AgentHarness` 驱动有界的“模型 → 工具 → 下一步”。传输层继续负责协议、流式响应与连接；业务层负责工具权限、课表校验、预览与用户确认。相同调用 ID 与参数复用已完成结果，改变参数必须使用新调用 ID。新的读取调用会重新读取当前材料，不能被旧查询缓存遮住。

`AgentMailbox` 区分插嘴与排队。插嘴在下一步请求前加入；排队在当前回合完成后开始。停止或失败暂停收件箱，不能清空待处理消息。工具执行期间收到输入不会中途破坏调用与结果的配对。

界面统一先将发送中的补充作为排队候选，胶囊内提供编辑／删除／引导。引导将同一候选改为 steering，保持 id 和内容，取消或完成边界不会重新创建一条重复消息。

`AgentContextPolicy` 默认容量 256k，预算内保留完整请求。接近预算时压缩较早的工具结果，保留用户消息、近期调用及其结果，并明确标注被截断的材料可重新读取。估算只用于本地预算，界面 token 数使用服务商实际返回的统计。它不是服务端上下文容量探测器，也不是模型生成的长期记忆。

`AiMaterialWorkspace` 持有本次原始材料：分段读取文字、按页读取 PDF、按原页坐标裁切图片或渲染 PDF 区域。概览图片与原图分开，细节请求不反复压缩上一张截图。材料内容始终作为数据，不能取得用户指令的权限。

多文件工作区保留每个源文件独立的页码与文本偏移，`file=0` 为目录、`file=1..N` 选文件；单文件旧调用仍兼容。首屏概览有预算，但原文件的后续文字／页面仍可由工具读取。消息收件箱的值保留整组图片，编辑和引导不重新生成附件或只取第一张。普通助手历史沿现有图片 marker 顺序保存多张，V1 备份复用已有附件数组，不引入 Room 迁移。

`TASK_WORKSPACE` 使用 `AgentTaskFiles`，只访问本次临时目录，写入带版本哈希，编辑要求原文精确匹配且唯一。`AgentJavaScript` 使用 AndroidX JavaScriptEngine 的隔离进程执行同步 `main(input)` 数据转换，没有 DOM、网络或任意手机文件访问。工作区在本轮结束时释放。

## 教务与数据边界

入口先重新加载本机适配目录，包括仓库更新与本地自用脚本。当前地址与适配入口的 origin 明确一致时直接使用本机适配，不调用模型；多个候选在本机选择。不会凭相同教务厂商、相似学校名或父域名套用别校脚本。

官方适配继续使用拾光 adapter → Bridge → `ImportDraft`，本地脚本采用同一协议、单列本地来源。无论来源如何，课程只能在本地校验及预览确认后写入数据库。保存自用适配需要用户明确确认，不自动上传仓库。

`EDU_WORKSPACE` 是显式绑定当前 WebView 文档的另一种能力，可查询同源接口或运行标准拾光异步脚本，支持真实 DOM、fetch 和 Bridge 提问，不能把它描述成隔离进程的纯数据 JS。生成脚本执行携带独立标识，标识从异步 Bridge 调用送到 Native；新任务拒收旧标识，防止停止后晚到的课程或完成事件污染下一次导入。默认官方 Bridge 消息继续兼容，内部标识不改变上游脚本协议。

入口只提供脱敏网页地址和标题，模型需要主动读取页面及接口线索。`EduImportEvidence` 在工具实际执行后记录调查，阻止模型仅凭入口提交课程；页面解析需要调查后明确声明 `PAGE_FALLBACK` 理由，不用客户端预定的厂商路由替代模型决策。

特殊课程通过 `TIME_SLOT_COURSES` 的按 id 局部补丁接入原有设置预览／确认／事务，复用领域模型校验，保留未提及字段及其他特殊课程，不把固定时段标记误当成普通课表课程。

Chat Completions 与 Responses 使用相同任务规则，Responses 保留原生调用/结果和不透明推理项目。ChatGPT 账号沿现有 OAuth 传输，不假定其具有 Files 上传接口；默认文件处理发生在手机本地。

## 验证边界

单元测试覆盖循环上限、取消、调用重放、协议配对、材料裁切参数、上下文压缩与文件版本检查。编译和模拟传输不等于真实学校登录或实际模型账号验证；设备和账号验证须在对应报告单独记录。
