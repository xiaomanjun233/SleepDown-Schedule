# 全新的节次时间编辑

SleepDown 现在将“课程属于第几节”和“这一节具体几点开始”分开管理，让同一张课表可以适配不同季节、校区或教学安排，而不需要重复导入课程。

## 一张课表，多套作息

每张课表都可以建立多套独立的作息方案，例如“默认作息”“夏令时”和“冬令时”。课程仍然绑定原来的节次编号，切换方案时只改变每节课对应的开始、结束时间，不会复制课程，也不会打乱课程位置。

不同课表的节次结构、作息方案和时间设置彼此隔离。切换课表后，首页、日视图、周视图、课程提醒、桌面小组件和今日助手都会使用该课表当前启用的作息方案。

## 上午、下午、晚上分段设置

节次可以按上午、下午和晚上分段配置。你可以决定启用哪些时段，并分配每个时段包含的节数。各时段拥有独立的起始时间，因此午休和晚休不再需要用一个超长课间来模拟。

调整节数后，下方完整时间线会立即刷新，便于直接检查新的节次分布。

## 手动模式与自动匹配

### 手动模式

适合学校作息不规则、每节课时间差异较大的情况。你可以逐节设置开始和结束时间，并在上午、下午或晚上继续增加节次。

### 自动匹配模式

分别设置上午、下午和晚上的开始时间，再填写单节课时长与普通课间时长，应用会自动生成完整时间线。

如果某两个相邻节次之间存在大课间，可以添加“特殊课间”。从已有手动时间切换到自动匹配时，应用也会识别同一时段内与普通课间不同的间隔，并将其保留为特殊课间。

## 自动生成，也可以局部微调

自动匹配并不意味着所有时间都必须完全统一。你仍然可以单独修改某一节的开始或结束时间，该节会被标记为手动覆盖，其他节次继续保持自动计算。

需要恢复时，可以清除该节的覆盖，让它重新跟随自动匹配规则。若修改后与前后节次发生时间重叠，应用会在保存前明确提示，避免产生冲突时间表。

## 保存与课程重映射

离开详细设置时，应用会询问是否保存本次修改。只有确认保存后，配置、作息方案和最终节次时间才会在同一事务中提交。

如果新增、删除或重新分配了节次结构，应用会提示将课程按照原节次的实际时间映射到新的节次，尽量保持课程原本所在的时间位置。仅修改作息方案的具体时间不会移动课程。

## 数据保护

升级后，应用会检查每张课表的详细配置、当前节次和作息方案是否一致。若旧版本留下了缺失的物化节次或空时间线，会优先从仍然存在的自定义方案恢复；通知设置等无关操作也不会再改写节次与作息数据。
