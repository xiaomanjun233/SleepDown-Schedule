# 横屏与平板界面改造

本轮在 `codex/tablet-sidebar` 实现，延续 [Nexio 调查与首轮侧栏报告](2026-10-01-pad-landscape-nexio-review.md)。侧栏首阶段提交为 `1d8f446`，本轮界面大改另作提交。没有修改数据库、备份、口令、ICS、组件身份或版本号。

## 最终需求

- 使用 Nexio 的窗口宽度判定：达到 600dp 即显示侧栏，无高度门槛，手机横屏可触发。横屏且达到该宽度时，首页、课程管理和课表管理使用宽窗口布局；系统设置中调整显示大小后，是否触发仍取决于实际窗口 dp。
- 横屏三点菜单移除，五项课表操作归入侧栏；课程管理和课表管理为独立导航入口。个性化编辑按钮移至右侧原三点按钮位置。
- 侧栏全局悬浮在首页、设置、课程管理、课表管理的页面切换之外。下方页面使用缩放、动态模糊及淡入淡出，侧栏不跟随缩放或模糊。
- 横屏弹层在中心显示，从下方非线性进入，退出内容保留到动画完成；不再使用原无缝锚点变形或半屏 QuickSheet。课程编辑、选择器和快速设置保留原字段排版。
- 侧栏是带折射、较低模糊度的毛玻璃；弹窗是更高模糊度、更厚明暗衬底的毛玻璃。

## 布局与入口

| 场景 | 结果 |
| --- | --- |
| 今日页 | 延用日期/助手与课程列表双栏，补齐 600dp 起的矮横屏尺寸 |
| 周视图 | 侧栏旁保留完整周课表与原移动、缩放、快速编辑入口 |
| 设置 | 复用原宽窗口两栏内容，右栏切换接入新转场 |
| 课程管理 | 左侧课程组列表，右侧原课程详情字段与安排编辑 |
| 课表管理 | 左侧课表列表，右侧概要、周课表预览及使用/设置/重命名/分享/删除操作 |
| 横屏弹层 | 表单上限 680dp，快捷菜单 520dp，快速设置 600dp；高度受安全区、键盘与 640dp 上限约束 |

矮横屏默认使用折叠侧栏，内容占位为 96dp；展开宽度按窗口比例约束。今日双栏不再要求 840×560dp，紧凑横屏减小顶部间距与栏间距。真实窗口尺寸与剩余内容宽度分别保留，侧栏占位不会使页面误判成窄屏。

侧栏操作复用已有添加、手动导入、教务导入、周数选择和课表设置回调。课表长按在横屏直接进入新管理布局；管理页预览复用静态周课表，分享复用已有 SleepDown 口令和 ICS 编解码器。新课表及重命名沿用公共名称表单，删除仍要求确认并保护最后一张课表。

## 材质与动画

| 表面 | 模糊 | 折射与衬底 |
| --- | --- | --- |
| 侧栏 | 16dp | lens height 4dp / amount 8dp；浅色白色 0.68，深色 `#1F1F1F` 0.66 |
| 中心弹窗 | 28dp | 不叠加强折射；浅色 `#F2F3F7` / 深色 `#1F1F1F` 0.76 |
| 弹窗内部组 | 不重复采样模糊 | 浅色白色 / 深色 `#2E2E2E` 0.66 |

这些是当前材质参数，未作真机帧率结论。中心弹窗通过 `glass/` 的屏幕坐标映射消费页面完整 Backdrop，采用 0.5 的采样比例，避免自行创建生产层或循环采样。无 Backdrop 或 Android 12 以下保留相同圆角、内容和交互，降级为实色。

中心菜单采用阻尼 0.86、刚度 380 的位置弹簧从屏幕下方进入；退出为 240ms 非线性位移，叠加淡出。页面切换缩放范围为 0.96→1，动态模糊上限为 10dp；稳定后卸载 RenderEffect 与临时裁剪。切换阶段屏蔽内容触摸，避免对退出页面执行操作。

横屏提前选择中心菜单分支，绕过原首页个性化、导入、课程编辑和快捷菜单的锚点快照/连续变形；详细设置交接跳过原全页快照捕获。跨 Activity 协调器横屏不启用原生无缝后端，继续执行会话释放回调。竖屏原路线保留。

## 保存与返回

- 课程管理左侧换课、侧栏切页与详情返回均复用未保存确认和课程冲突检查。完成数据库保存后才执行跳转；失败仍留在详情并显示重试提示，不清除草稿。
- 多课表快速设置保留原保存方式；进入详细设置前先保存当前草稿。
- 课程快捷菜单关闭完成后才执行编辑、复制、快速编辑或删除。重复关闭不会重复执行，生命周期清理会取消尚未执行的操作。
- 今日助手只调整横屏展示、附件菜单与开合轨迹，消息流、执行确认、服务和导入处理保持原实现。
