# 1.2.6 Beta7 修复与发布记录

本轮覆盖调休编辑、助手操作链路、壁纸保留、首页动效与包体清理。前期调查和验证见 [调休与 Agent 稳定性记录](2026-09-20-adjustments-agent-stability.md)，产品文案见 [Beta7 更新日志](../release-notes/v1.2.6_beta7.md)。用户在打包过程中追加授权发布 Beta7；未要求安装或合并主分支。

发布后发现的桌面图标跟随回归及修复验证见 [桌面图标深浅跟随修复](2026-09-20-launcher-theme-resource-fix.md)。以下保留首次发布时的调查与产物记录。

## 最后追加的交互修订

- 日、周视图的“补／停”角标改为胶囊，沿用删除角标的 5dp 外悬位置，位于卡片右上角外侧。角标和卡片一起隐藏、运动，正文恢复原来的布局空间；周视图为首行角标保留顶部绘制余量，平板末列保留尾部余量。
- 节次编辑退出比较进入前的草稿与当前实际时间安排。进入时把自动模式物化为编辑时间线，以及拖动压缩的恢复记录，不算用户修改；时间改回原值后可直接退出，且不回写父页面草稿。
- 新建作息、修改其他作息、节次分段数量和课程重映射操作仍计为实际修改，避免因为时间最终相同而遗漏待保存的数据关系。

## 包体调查与清理

对比仓库本地留存的 `1.2.5_beta3` 包与本轮清理前的签名包：

| 项目 | 压缩后增长 |
| --- | ---: |
| DEX 代码 | 285,213 字节 |
| res 资源 | 433,561 字节 |
| assets | 479 字节 |
| 元数据 | 3,886 字节 |
| 原生库 | 0 字节 |
| APK 总体 | 718,574 字节 |

资源增长与后续实时活动新增固定图标资源有关。APK 中确认有 20 组图片各重复三次，分别服务固定桌面图标、跟随系统深浅的桌面图标和实时活动，重复图片合计 923,440 字节。R8 与资源压缩已经开启，但这些资源名均被实际使用，不能当作未使用资源移除。

保留四种原图各五档密度，以资源别名共享。默认与 night 别名选择对应深浅图，实时活动的 drawable 名称指向明确的固定深浅图，不依赖跟随模式。保留 Manifest 的 Launcher alias、应用图标和通知入口。删除 50 个逐个校验为相同的源码副本，以及 2 张已无引用的旧预览图；生成脚本不再生成重复副本。

加入 [Measure-ApkSize.ps1](../scripts/Measure-ApkSize.ps1)，可按 DEX、资源、assets、原生库和元数据对比两个 APK，并按内容哈希查出重复文件：

```powershell
.\scripts\Measure-ApkSize.ps1 -Apk '新版本.apk' -Baseline '旧版本.apk'
```

清理后的中间签名包为 6,327,410 字节，相比清理前 7,258,511 字节减少 931,101 字节（12.83%）；图片数量从 70 份减为 30 份，独立图片哈希集合完全一致，重复资源为 0。保留现有壁纸、介绍图、学校适配资源、原生库和数据兼容链路。
