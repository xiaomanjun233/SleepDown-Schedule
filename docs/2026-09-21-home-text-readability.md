# 首页壁纸文字的软阴影可读性

## 当前实现

壁纸上的日期、节次、时间与分段文字继续使用现有字色、字重和单次 Text 软阴影方案。课程卡片的彩色文字按后续用户反馈，增加局部背景明度适配，保留课程色相与饱和度。

- 依据文字实际排版范围采样，扣除首页根节点在窗口中的偏移；保留横竖屏和已保存壁纸裁切的映射。
- 采样副本最长边从 128 提升到 512，减少小字号只落在一个采样行的问题。副本仍在后台生成；有壁纸模糊时使用模糊后的图像。
- 按实际行高划分短文字区段，每区段取 3×5 点的局部对比度分布，关注较难读的 10% 区域，过滤孤立极值；避免一个字落在暗处却被整行亮处掩盖。透明的次级文字适当加强保护。壁纸调暗先作用于 sRGB 通道，再计算线性亮度。
- 阴影分为八档强度，对比度低于 5.2 时开始保护，已启用时升至 6.0 才退出，并以 160ms 平滑过渡。位置和壁纸输入不变时复用判断，背景冻结时暂停采样。
- 浅色文字配黑色短柔影，深色文字配居中的白色柔光；半径按字号与屏幕密度计算，限制在 2.6–6.2dp，局部冲突越明显阴影越浓。文字颜色、透明度、字体和布局沿用原值。

## 卡片彩色文字与明暗交界

根据后续四张截图反馈，卡片彩色文字改为按每段文字下方的背景调整 HSL 明度，保留课程原色相与饱和度，原色已可读时不修改。背景来自缓存的壁纸副本，结合卡片透明度、模糊、染色以及文字在底部渐亮区域的位置估算；这是局部材质近似，并非 GPU 像素回读。无有效采样时沿用旧的明暗字色。明暗方向切换保留迟滞，颜色以 180ms 过渡；静止时复用采样，滚动时背景亮度变化不足 0.012 则复用颜色判断，背景冻结期间暂停采样。

周次标题的普通和无界布局均接入软阴影，后者保留自动缩字。壁纸文字由整段采样改为按行拆成短区段判断，阴影保护门槛调整为 5.2 / 6.0，半径按字号的 0.28 / 0.36 倍计算并限制在 2.6–6.2dp。继续使用单层软阴影，不添加描边、不改变壁纸文字字色。
