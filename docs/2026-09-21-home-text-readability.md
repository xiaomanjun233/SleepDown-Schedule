# 首页壁纸文字的软阴影可读性

## 当前实现

按用户确认，继续使用现有字色、字重和单次 Text 软阴影方案。改进范围为直接显示在壁纸上的日期、节次、时间与分段文字，不改课程卡片的彩色文字规则。

- 依据文字实际排版范围采样，扣除首页根节点在窗口中的偏移；保留横竖屏和已保存壁纸裁切的映射。
- 采样副本最长边从 128 提升到 512，减少小字号只落在一个采样行的问题。副本仍在后台生成；有壁纸模糊时使用模糊后的图像。
- 由 5×3 点的平均亮度改为 7×5 点的局部对比度分布，关注较难读的 10% 区域，过滤孤立极值；透明的次级文字适当加强保护。壁纸调暗先作用于 sRGB 通道，再计算线性亮度。
- 阴影分为八档强度，启用与退出采用不同门槛，并以 160ms 平滑过渡。位置和壁纸输入不变时复用判断，背景冻结时暂停采样。
- 浅色文字配黑色短柔影，深色文字配居中的白色柔光；半径按字号与屏幕密度计算，限制在 1.2–2.8dp，局部冲突越明显阴影越浓。文字颜色、透明度、字体和布局沿用原值。
