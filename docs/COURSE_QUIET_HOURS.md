# 上课自动安静

在通知设置的“上课自动安静”中，分别启用自动勿扰和自动静音／震动。两项功能跟随当前启用的课表，并独立于课程提醒开关；默认关闭。

可以设置提前开启、下课后延迟恢复，以及课间保持时长。功能使用课程实际逐节时间、单双周、学期范围和调休安排；相邻课程在保持时长内合并，中午等较长空档会恢复。切换课表、修改课程或作息、关闭功能、重启、系统时间和时区变化后，会重新计算状态和下一个触发点。

开启前记录原铃声模式，下课后仅恢复仍由应用维持的声音状态，保留课中手动调整。Android 10 及以上使用独立的应用自有自动勿扰规则，与原有实时活动手动勿扰按钮分别控制；Android 8/9 沿用系统兼容接口，并记录、按状态恢复原勿扰过滤方式。声音切换引起的旧系统勿扰变化也保留恢复记录。恢复记录只保存在本机，不进入备份。

系统勿扰访问权限用于勿扰及可能涉及勿扰的声音切换。通知设置提供授权入口，未授权时不执行自动切换。允许精确闹钟及后台运行可减少锁屏时的触发延迟；未获得精确闹钟权限时按系统允许的闹钟方式执行。设置本身随 `.sleepdown` 备份保存，旧备份缺少此项时保留本地设置。
