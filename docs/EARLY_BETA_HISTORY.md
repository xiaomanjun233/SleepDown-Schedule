# 最初十个 Beta：1.01—1.10

这份记录按**当时应用内更新日志**整理，而不是根据旧截图猜测功能归属。日志可在提交 `9879234` 的 `app/src/main/java/com/example/courseschedule/MainActivity.kt` 中逐条核对；`1.03 beta` 及更早条目已出现在 2026-05-27 的初始仓库记录 `837a7ad`。旧版使用过 `1.0 beta`、`1.01 beta` 这样的写法，和今天 `1.2.6_betaN` 的轮次命名不同，不能把它们解释为当前 1.2.6 的十次候选版。

| 版本 | 当时日志记录的变化 |
| --- | --- |
| 1.01 beta | 修复教务导入预览与节次信息；增加组件测试、日志抓取、更新日志与下载入口；优化课程编辑删除范围；周视图切换周加入课程卡片甩尾过渡。 |
| 1.02 beta | 修复部分 CAS 页面中教务 WebView 只显示半截；接入 Custom Tabs 登录；优化西南大学节次时间表，并在通用导入预览中增加节次检查。 |
| 1.03 beta | 加号菜单连贯展开、课程卡片无缝展开与返回；扩大卡片通透度调节范围；优化壁纸、甩尾动画、桌面组件与实时活动提示，增加 MagicOS 10 支持。 |
| 1.04 beta | 首次启动课程卡片飞入；增加隐藏后台卡片功能；修复重启后自定义壁纸可能丢失；适配 120Hz 动画。 |
| 1.05 beta | 增加多课表管理与复制课表口令分享；优化首次启动掉帧和编辑卡片弹窗动画。 |
| 1.06 beta | 竖屏、横屏壁纸区域可分别调整；增加课程卡片字体大小调节；修复液态玻璃分界线，优化加号菜单与首次启动动画。 |
| 1.07 beta | 重整个性化面板与课程卡片信息层级；调整圆形图标按钮和滑块默认值操作；首页日期可回到本周，日视图可左右切换日期；修复壁纸模糊马赛克。 |
| 1.08 beta | 优化课程卡片打开和收回动画，以及顶部与背景之间的渐变模糊过渡。 |
| 1.09 beta | 增加 AI 导入作为教务抓取失败时的补充；当时仅 DeepSeek 和小米 MiMo 完成全流程测试，DeepSeek 不支持图片导入；继续调整玻璃参数与菜单动画。 |
| 1.10 beta | 优化课表切换与周视图渲染；改进长按编辑、删除单周课程确认和超长课程拖拽；修复多课表管理进入设置时跳回默认课表，优化设置页滑动与切换。 |

上述文字是对原日志的压缩转述。原日志中对模型、系统和特性的支持范围属于**当时状态**，不作为当前功能保证；当前能力应看代码、构建配置和[功能地图](FEATURE_MAP.md)。
