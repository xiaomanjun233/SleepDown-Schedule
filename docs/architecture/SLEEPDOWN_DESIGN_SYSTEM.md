# SleepDown 设计系统

动效参数、路线和资源生命周期的维护入口见[动效维护入口](MOTION_MAINTENANCE.md)。

从功能出发的入口见[功能地图](../FEATURE_MAP.md)。本文说明共享的页面语言和实现边界；设计参数与组件状态以当前代码为准，旧验收截图只记录对应阶段的视觉结果。

SleepDown 设计系统是业务页面与 Miuix、Backdrop、Compose 实现之间的稳定 UI 语言。它的目标不是让每个界面长得一模一样，而是让不同页面在层级、留白、材质、前景色和交互反馈上属于同一个产品。

规范分为两层：

- **不变量**保证家族感、可读性和技术安全；
- **场景风格**允许设置页、内容页、沉浸任务页按信息密度和任务目标做不同布局。

换句话说，新页面先选择最接近的“句式”，再写自己的内容，不复制另一个页面的全部外观。

## 设计 DNA

SleepDown 的界面由五个共同特征形成，而不是由单个圆角或某一种玻璃决定：

1. **层级清楚**：页面背景、内容分组、临时浮层和最终决策各占一层，不用多层同权卡片堆叠。
2. **留白连续**：页面边缘、分组之间、组内行和控件内部形成从疏到密的节奏。
3. **材质有来源**：玻璃必须知道采样哪个 Backdrop domain；无玻璃降级仍保留相同几何和语义。
4. **前景色成套**：同一表面内的标题、正文、字段、图标、箭头和禁用态来自同一对比度体系。
5. **运动有来处**：页面从真实锚点进入并回到真实锚点；稳定终态不长期持有转场 clip、快照或离屏壳。

只要这五点一致，设置表单可以规整，AI 对话可以更自由，附件预览也可以完全沉浸，而不会脱离 SleepDown 风格。

## 代码入口

```text
core/ui/designsystem/
├── SleepDownDesignTokens.kt    # 稳定尺寸、间距、圆角与前景色来源
├── SleepDownSecondaryPage.kt   # 设置/内容/沉浸三种可覆盖的内容节奏
├── SleepDownDialog.kt          # Dialog/Alert/Overlay、标题栏、按钮、输入字段
├── SleepDownQuickSheet.kt      # 选择器外壳、QuickSheet 表面与操作按钮
└── LandscapeMenu.kt            # 明确接入的横屏表单飞入动画与窗口宿主
```

设置页面的 Backdrop 和顶栏由 `DetailActivityScaffold` / `CouiSettingsPageScaffold` 管理，直接使用 COUI 页面壳。设计系统提供其下方的内容节奏，不接管 Activity、导航、Morph 或业务状态。

| 使用场景 | 统一入口 |
| --- | --- |
| 二级页页面壳 | `DetailActivityScaffold` |
| 设置型、内容型或沉浸型列表节奏 | `SleepDownSecondaryPageList` |
| 标准或紧凑居中玻璃表单 | `CenterLiquidDialog` / `LiquidDialogSurface` |
| 表单标题、取消、完成 | `LiquidDialogHeader` |
| 一至三个确认操作 | `LiquidAlertDialog` / `LiquidAlertActions` |
| 必须采样同窗口底层的提醒 | `LiquidAlertOverlay` |
| 日期、时间、数字或小型编辑器 | `SleepDownPickerDialog` |
| 教务工具及作息对齐单选 | `LiquidAlertDialog` + `LiquidDialogChoiceCard` |
| 胶囊按钮与输入框 | `DialogLiquidButton` / `DialogCapsuleField` |
| 改造版 Miuix 居中弹窗表面 | `centeredDialogBackdropModifier`（业务优先调用上层组件） |
| 底部或内层 QuickSheet 表面 | `quickSheetBackdropModifier` |
| QuickSheet 操作 | `QuickSheetLiquidAction` |

## 横屏与宽窗口

当前窗口宽度达到 600dp 即显示侧栏，不要求最小高度；横屏时主页启用双栏，矮横屏默认折叠侧栏。侧栏位于主页面切换容器之外，页面缩放、动态模糊与淡入淡出只作用于下方内容。横屏首页移除三点按钮，其操作归入侧栏，个性化编辑按钮占据原三点按钮的位置。

宽屏课程编辑与手机共用从源卡展开和收回的无缝过渡，目标表单按当前侧栏和安全区居中。周视图的新增卡片共用单节课的格子尺寸，取消编辑时原位接回，三秒后缩小淡出。侧栏「导入课表」在右栏打开统一导入页，两侧各留 16dp。口令／文件、教务选校和导入预览由该页托管，导入历史和记录详情在栏内淡入淡出。选中教务适配器后沿用对应的登录取课流程。

手机周视图课程卡片的默认圆角为 8dp，新增格使用 13dp，课程文字向内收 1dp。个性化滑条保留百分比存储，按各自窗口的卡片几何映射。快速编辑的相邻课程涟漪在落地压缩阶段发出，数据库提交和浮层淡出仍各自完成原有的卡片交接。

设置、课程管理与导入共用 COUI 页面底色。宽屏侧栏和顶部导航与手机底栏共用各模式的材质参数，表面继续采样当前页面。侧栏外轮廓和选中项共用 32dp 圆角。收拢后为 52dp 高的胶囊，今日、课程表、设置共用 48dp 高的分段控件和弹性按压容器。真实范围注册为首页下拉助手手势排除区。

宽屏设置将分类作为右栏的一级页，切换时在栏内播放缩放、淡入淡出和模糊。作息管理、特殊课程列表和调休课表沿同一个右栏横滑进出。调休单独提交数据库事务，课表设置的草稿保留在父页。

启用回弹的公共列表和首页日／周视图保留同一个纵向输入节点，滚动范围为零时仍支持回弹。带搜索框的折叠顶栏在列表铺满时把剩余位移交给回弹，松手时仅播放回弹。课程卡片拉伸期间，周视图暂停纵向输入。

COUI Dialog 在窗口长边至少 840dp、短边至少 480dp 时居中。COUI 底部 Sheet 底部居中，宽窗口按网格取六列，最宽 540dp。大屏高度上限为 800dp，并受顶部留白和 IME 限制。调休预览和通知教程在大屏按内容测量高度，作息编辑使用可用高度。面板保留顶部圆角和从所在场景取样的工具栏。

课程编辑与个性化表单在 Preparing 阶段完成布局，随同一个外壳显示并保留到关闭完成；两种材质模式不再延迟挂载表单或叠加逐行入场。液态模式的大弹窗使用 `MorphDialogSurface`：保留课程或原面板颜色及透明度，在先绘制的完整场景上运行半分辨率纯高斯模糊，再以原分辨率绘制染色与 Kyant 默认高光描边；不运行折射、vibrancy 或材质提亮。课程编辑沿用真实源卡片到完整场景的交接，外壳模糊保留到 Open；副本和表单的临时动态模糊仍在稳定后释放。凝光首页个性化及添加表单共用 `Form` 原生模糊与薄染色，避免叠加深色 Dock 预设。个性化外壳按当前窗口位置和尺寸采样，模糊半径保持在屏幕像素坐标内。独立 Dialog 仍在自己的窗口托管内层 Picker，背景景深继续消费完整 underlay。

凝光全局模式统一使用凝光课程卡片，不再提供课程卡片的独立凝光开关，也不进入液态或高斯卡片分支；原有液态偏好保留供切回时使用。原生材质暂不可用时保留普通课程染色。表单按钮和输入框从所在面板的前景决定明暗，背景、正文和占位文字使用同一判断。课程编辑顶栏渐变模糊覆盖 82dp，最大模糊 22dp，仅采样滚动表单；标题与按钮保持原有 70dp 布局，渐变不额外提亮背景。

上述课程卡片路线仍是旧 ColorOS 能力实现，尚未迁入 COUI-Kit；跨品牌未安装原生课程 renderer 时，代码仍会进入原液态／高斯分支。不能把 API34+ 的 Kit 控件门控当作课程卡片已完成跨品牌迁移的证据，当前入口盘点见[材质报告](../reports/2026-11-08-glow-material-entry-audit.md)。

液态课程编辑的预载表单在外壳展开量 24%～62% 叠化，课程透明外壳在形状进度 8%～48% 接入；凝光继续沿用原始时钟 35%～70% 的表单窗口。应用内反向保留时钟速度，同一进度使用同一几何、投影和透明度。个性化面板沿用课程卡片的位置曲线和弧线，从顶部按钮下移并逐步展开。尺寸使用 Material 标准贝塞尔曲线 `(0.4, 0, 0.2, 1)`。运动中的材质绘制为普通圆角矩形，模糊按屏幕坐标取样。前景表单预先按最终尺寸测量，独立等比缩放并在展开量 24%～62% 显现。课程会话按卡片独立持有，允许同卡快速反向和 A/B/A/C 连续输入；已关闭会话到 Idle 才释放，背景模糊取各会话最大需求。退出表单复用 GPU 录制，并将命中树移到首页下层，让真实卡片触摸能立即响应。原生并列加号的应用内返回复用已采集的真实按钮层，不再创建第二个原生 FAB 作为副本；右上角按钮也在隐藏前保留真实录制，避免从空白区域裁切。跨 Activity 金标返回在设备声明支持时通过 `sharedView.bitmap` 更新真实返回画面，位图资源保留到 BACK 完成。

输入边界与视觉定位分开：侧栏全屏定位节点不注册触摸，禁用拦截只属于实际尺寸的侧栏子节点。首页下拉手势放在 underlay，不能成为 Miuix 弹层 host 的祖先。横屏表单的空白拦截位于真实内容后方，动画期屏蔽层在停稳后卸载，避免吞掉取消按钮和滑块事件。

横屏课程管理复用原详情字段、冲突检查和保存确认，左栏保留两列瀑布流卡片，选中项压灰。侧栏切页或换课须等待确认，保存失败时保留草稿。多课表切换复用原卡片、重命名、分享、删除及快速设置，保留黑场与卡片无缝开合。当前卡片、标题与操作区在右侧布局区居中，Pager 使用完整窗口，堆叠卡片允许延伸到悬浮侧栏下方。侧栏此时采样 Picker 场景，导航先取消浏览再切页。快速设置先保存草稿，再通过共用的异步转场打开详细设置。

关于应用、软件更新和更新日志与其他设置页共用 COUI 明暗底色，头图仅在关于页的版本卡片内绘制。宽窗口侧栏与内容区使用一致的页面底色和采样坐标。竖屏课程与设置的圆角切换保留，交界处底色跟随应用明暗主题。

顶部导航是最大 300dp 宽、52dp 高的悬浮控件。展开侧栏按钮和分段选项放在共用弹性容器内。收展时横纵采用各自的弹簧，今日、课程表、设置的文字沿同一材质表面依次移动；栏目保留测量尺寸，过渡进度由放置和绘制读取。侧栏的浅色表面使用柔和阴影分隔。首页日／周 Pager 在侧栏方向扩展绘制视口，内容停稳后恢复页面边距。

首页日视图入口使用 COUI `Certificate`。周视图入口使用 ColorOS 日历的底栏图标，未选中为线框，选中为实心。手机底栏的设置项按选中状态切换实心和线框齿轮，侧栏和其他设置入口使用实心齿轮。多课表管理使用 `Filled.MultiPhone`，设置里的 AI 助理分类使用 `Filled.Headset`。凝光和液态使用同一套图标选择规则。普通矢量沿用控件前景，AI 模型设置和日视图助手的对话标题使用 `Filled.AI` 的渐变。

手机竖屏使用并列底栏。加号在今日与课程表分离，在设置并回；点击从真实加号打开统一导入页，返回使用原加号锚点。菜单通过 `glass/GlassDropletSurface` 与 `HomeDropletMotion` 绘制局部液滴轮廓，颜色在预乘透明度下插值。保留单一液滴主体，主运动缓入缓出；短促收圆与位移同时起步，高度先于宽度展开。退出时主体收小领先靠近锚点的位移，最后一段接近按钮的同时恢复正常尺寸；开合末段各保留一次轻微过冲和回弹。轮廓保持圆润，仅保留轻微整体锥度，不生成局部细颈或向按钮突出的尖角。动画停稳后回到原菜单材质，释放临时形变分配；较低系统使用普通轮廓降级。

课程管理和导入的完整页面路线从实际菜单整体展开，源菜单与页面内容在同一个外壳里交接；页面缓存以覆盖外壳的比例缩放并裁切揭示，文字动态模糊随交接变化。页面采用单调的缓入缓出，无过冲、回弹或反向位移；交接时保留源圆角，行进中保持圆角卡片，只在进入全屏的末段平滑放开圆角。Android 13 及以上复用原玻璃边缘折射作用于合成后的文字和表面，稳定态释放临时特效；较低系统保留几何与模糊。真实布局和玻璃采样坐标保持稳定，返回图标与背景同步交接；独立课程卡片编辑器继续使用自己的路线。本入口不将液滴动效全局套到原有弹窗。小菜单关闭保留前 150ms 的收缩节奏，只延长最终小液滴恢复按钮的过程。实现与验证记录见 [2026-10-02 横屏改造](../2026-10-02-landscape-overhaul.md)。

并列 Dock 与普通 Dock 使用相同的底部安全区和 8dp 间距；并列模式隐藏 Dock 对齐设置并保留原值。普通模式“课程”使用周视图图标，加号按钮与动画源图标使用 24dp 的 Compose Rounded Add，54dp 点击区域不变；菜单中的添加课程也使用同款 Compose 加号。打开加号菜单时保留右上角三点。Dock 与加号稳定态相距 6dp，加号的透明度、基础模糊与折射参数对齐 Dock。加号及教务搜索框全程使用原 `LiquidButton` 材质，Dock 恢复自身容器材质；按用户要求撤掉与原玻璃不一致的控件间 SDF 融球连接，保留分离/回收动画与独立的输入、按压形变和滑块。搜索框与操作按钮使用原 8dp 间距，整体在布局区居中。菜单液滴保留单一主体，不叠加前后缘错时挤压或脱离主体的后随小球。

## 二级页面的三种风格

### 1. 设置型 `Settings`

适合开关、选择、说明和表单项，例如通用设置、AI 设置、今日助手设置、课表详细设置。

- 设置首页使用 COUI 折叠标题与悬浮搜索；普通二级设置页使用 COUI 紧凑顶栏。原 Miuix 设置页面壳已按用户要求移除。液态搜索与教务页共用玻璃样式，位置仍由设置顶栏负责。
- 设置首页直接按 `SettingsGroup` 分组，不显示分类名；二级页可按内容保留分类标题。首页应用头部下方的线对齐标题起点，其余图标行的线沿用普通缩进；设置分隔线使用 COUI `outlineVariant`（浅色 `#1F000000`、深色 `#33FFFFFF`），与系统原版同步。
- 关于页的版本卡沿用 ColorOS「关于本机」的两侧 16dp 边距和底部对齐的 40dp 更新按钮。手机首卡高 328dp，展开宽屏首卡高 240dp，头图显示完整应用名和版本。按钮从头图采样透明凝光材质。下方并排放置「关于开发者」和项目仓库，项目致谢沿用带 GitHub 图标的设置行。
- 检查更新进入独立软件更新页。手机采用全屏背景、居中的版本与品牌及底部状态卡，宽屏沿用独立头卡布局。发现新版本时展开该版本的发布说明，同一版本在当前会话只自动展开一次。下载使用底部悬浮 COUI 胶囊，点击后在原位置显示下载进度；宽屏浅色更新说明使用有轮廓的浅色卡片，工具栏按钮加强软阴影。历史日志和自动更新设置从右上菜单进入。
- COUI 的页面边距、分组、分类标题和行内距由 `CouiPageDefaults` 及公共设置入口装配；列表与分组不能重复添加同一段留白。原 Miuix 路线保留自身间距。
- 一个设置组表达一个概念域，不为每一行再套独立卡片。
- 保存方式属于业务会话：即时保存、离页提交和显式完成都可以，但不能藏进设计系统组件。
- 原生开关行由整行承担最小 48dp 点击和无障碍语义，内部 COUI Switch 只测量 24dp 轨道并共享反馈源；不能给子开关再叠 48dp 点击区后增加父行内距。说明文字存在时按内容增高，液态开关保留自身控件与绿色。

### 2. 内容型 `Content`

适合历史列表、处理进度、阅读详情和课程管理等以内容为主的页面。

- 通常使用 58dp 紧凑顶栏；标题可左对齐，也可在左右操作对称时居中。
- 页面水平边距通常仍为 16dp，内容块间距采用稍紧的 12dp。
- 卡片用于表达对象或阶段，不把每一段正文都做成玻璃卡。
- 主操作跟随内容落点；跨列表的全局操作才放顶栏。

### 3. 沉浸型 `Immersive`

适合 WebView、附件全屏预览、截图选取、Morph 运动中的任务壳等需要自行控制坐标的页面。

- 可以不使用统一列表边距，但必须独立处理 `safeDrawing`、状态栏和导航栏。
- 可以隐藏标准顶栏，但必须保留明确且可返回的真实控件。
- 稳定 Open 终态应释放运动阶段的 clip、RenderEffect 和 Offscreen 合成。
- 沉浸不是忽略规范：前景色来源、触控尺寸、降级材质和返回语义仍必须一致。

`SleepDownSecondaryPageStyle` 是起点，不是限制。页面确有理由时可覆盖水平边距和分组间距；覆盖值应描述信息密度，而不是复制另一个页面的偶然数字。

## 二级页结构

一个普通二级页从外到内按以下顺序组织：

```text
Activity / Morph host
└── DetailActivityScaffold              # 背景、Backdrop、顶栏、安全区
    └── SleepDownSecondaryPageList      # 页面节奏与内容边距
        ├── 分类标题（可选）
        ├── 主分组 / 主对象
        ├── 次分组 / 补充信息
        └── 页面级操作或安全底部留白
```

### 顶栏选择

| 页面任务 | 推荐顶栏 |
| --- | --- |
| 设置首页 | COUI 折叠标题与常驻悬浮搜索 |
| 普通二级设置 | COUI 紧凑顶栏、逻辑起始方向标题 |
| 列表、详情、单一任务 | 紧凑顶栏，标题左对齐 |
| 左右操作对称、标题是稳定页面身份 | 紧凑顶栏，标题居中 |
| 全屏预览或网页任务 | 沉浸顶栏或临时控制层 |

居中标题必须为返回按钮和右侧操作保留相同视觉空间；如果右侧操作数量会变化，优先左对齐，避免标题看似居中但实际偏移。

### 页面留白

- 顶部位置由 `detailContentTopPadding()` 或 Scaffold 提供的真实 inner padding 决定，业务页面不重复叠加状态栏高度。
- 底部留白根据页面宿主决定：带首页 Dock 的页面保留 Dock 清空区；独立 Activity 只需要安全区和操作区。
- 平板详情 Pane 可增加外层内容 inset，但组内行高、文字层级和操作尺寸不随意放大。
- 新页面不得为单一分辨率写固定屏幕宽高；窄屏、横屏和字体缩放依靠约束自适应。

## 表面与内容层级

### 页面背景

设置与常规二级页使用 `settingsPageBackground(settingsVisualConfig(config))`。页面背景负责稳定明暗，不能把壁纸前景色直接带进设置卡片。

### 分组表面

`SettingsGroup` 表达同一概念下的一组操作。组内使用行、分隔线和必要的内联说明；除非存在独立点击对象或视觉状态，不再嵌套同等重量的玻璃卡。

### 内联展开

轻量、上下文强且展开后仍能清楚归属当前对象的内容，优先原地展开，例如课程管理详情中的周次。原地展开必须真实参与测量、点击和动画，不能只画一层视觉覆盖。

### 临时浮层

选择器、确认和短编辑属于临时层。它们必须使用正确的同窗口 Backdrop，且不能让 consumer 采样自己所在的 producer。跨 Activity 页面继续使用已有单向 Backdrop 与快照交接结构。

## 弹窗选择

凝光普通主按钮使用 Kit 默认填色；浮动加号等有色操作显式选择半透明采样。中性按钮可消费所在面板的下层源。管理页的源包括黑底与投光，预览卡片、按钮和文本在源外后绘制；Kit 按钮不再叠加旧个性化按钮的纵向白色洗光。

先按任务选择弹窗家族，再决定内容；不要先复制一个长得接近的弹窗。

Alert、Picker、输入弹窗共用 `ControlDialogs` 的凝光布局。窄窗口保持底部位置；宽至少 600dp 且高至少 480dp 时居中，卡片高度按 ColorOS 大屏参考限制在 470dp 和当前安全区以内。材质只能提供绘制和按压反馈，不替换窗口、内容或关闭会话。退出交接由实际完成回调驱动。

凝光 Dialog 以 COUI Demo 的原尺寸、Kawase 200、混色及窗口运动为基准；表面采样下层完整窗口，内部标准操作沿用 Kit 填色和反馈，不叠加第二次采样。完整弹窗窗口源只供下一层嵌套窗口，整窗源无消费者时直接绘制；同窗口的 Scaffold 复用源。普通 Picker 直接使用上游 Dialog、WheelPicker／CalendarPicker；特殊内容的标题与固定操作区同样复用 Kit。正文不重复绘制标题或底部按钮。普通选择器不启用全屏 IME 策略，输入表单单独处理导航区与键盘交集。

自定义Picker正文通过 `contentPadding` 显式使用 `CouiPickerFormPadding`（水平24dp、顶12dp、底16dp），不叠加旧2/4dp微边距；标准Wheel/Calendar由组件自身处理留白。凝光月历只保留自身年月导航，不加外层标题或重复日期标题。星期网格、课程调色板、作息表单等保留业务约束并共用上述内容节奏。课表设置顶部取消／完成保持原位置，详细设置固定在正文滚动区之外并按操作区内缩。

| 任务 | 组件 | 特征 |
| --- | --- | --- |
| 不可逆确认、错误、权限解释 | `LiquidAlertDialog` | 短标题、短正文、1–3 个明确动作 |
| 同一 Compose 根层且必须采样下层 | `LiquidAlertOverlay` | 与 Alert 同语义，挂在已录制内容之后 |
| 日期、时间、数字、多列选择、小型编辑 | `SleepDownPickerDialog` | 共用窗口，材质注入，正文与固定操作区可组合 |
| 多字段创建/编辑 | `CenterLiquidDialog` | 独立标题栏、可滚动正文、明确完成动作 |
| 与真实卡片/按钮连续变形的复杂编辑 | 既有 Morph 外壳 + 设计系统内容 | Morph 管轨迹，设计系统管内容 |
| 强上下文单选且内容很短 | 下拉或原地展开 | 不为一项选择打开全尺寸表单 |

### 弹窗正文节奏

- Picker 默认内容间距 12dp，密集数字控件可以保留自己的列宽算法。
- 教务工具选择与作息对齐共用 `LiquidDialogChoiceCard` 选项卡和 Alert 操作；正文按内容增高，最多 320dp，过长时内部滚动。标题、操作区固定，矮窗口继续服从安全区和 IME 的可用高度。
- 表单使用“标题栏 → 可滚动正文 → 固定操作区”，键盘出现时只允许一个层级负责 IME 位移。
- Alert 正文过长时内部滚动，动作区保持可见；不要把说明和主按钮拆成两个不同材质来源。
- 二操作通常横排；三个操作仅在标签能完整显示时横排，否则按组件既有纵向规则。
- 破坏性操作使用红色语义，但不能用红色填满整个普通设置组。

### 公共弹窗材质

标准 Alert、Picker 和命名输入在两种模式下统一使用凝光窗口、排版及材质。
已移除液态弹窗皮肤分支；其他液态按钮保留原按压反馈。业务不传独立窗口背景、旧中心动画或模糊半径。
自定义正文通过 `contentPadding` 提供内容留白，宿主负责 IME 和安全区。

窗口背景只采样父窗口；嵌套窗口使用完整下层窗口，按消费者需求录制。
Sheet 顶栏按钮显式采样滚动正文，正文 producer 与顶栏是同级节点；按钮保留透明模糊配方。
极致性能模式保留其原有无正文采样策略。
课程编辑、个性化等真实锚点 Morph 保留原有路线和 `morphDialogMaterial`，
不因普通弹窗统一布局改变其交接与保存语义。

### Popup 菜单材质

- 凝光 Android14+ 的课程 shortcut 与首页三点菜单直接使用 COUIKit `Menu`，保留196dp宽度及Kit窗口／材质，普通动作文字按目标ColorOS资源使用15sp regular与系统字体，白光轮廓由Kit样式配置。工具栏按真实按钮居中后避让，课程沿原列锚点左／中／右对齐；可见窗口、IME与RTL参与定位，向上弹出仍保留锚点间隔。动作列表不添加分割线，也不保留持久选中项。原生ColorOS共享按压遮罩在文字和图标之后绘制，单行项使用完整行高、横向内缩8dp及weight1胶囊；滑动只预选，抬手确认，移出／取消不提交。凝光动作有效选择后立即执行一次，菜单和课程浮层退场只清理资源。液态继续原菜单与Morph交接。
- 首页凝光顶栏图标按钮保留42dp尺寸与20dp图标，使用 Kit `TopAppBarButton` 的工具栏材质、轮廓和反馈。背景条是独立 producer，包含页面前缀与原渐进模糊；标题和按钮是后绘制同级节点，不得读取包含自身的 Dock 整页源。

- 设置普通下拉保留 COUI Item 触发行，弹出面板使用原改版 Miuix。透明、零 Insets 的 Miuix Scaffold 只提供本地浮层宿主；COUI 继续负责页面顶栏、正文与安全区，完整页面 producer 不包含浮层。下拉挂在真实 trailing Row 内，按当前窗口定位和收回。
- 普通下拉、列表和级联 Popup 由 `SleepDownLiquidDropdownPreference` / `SleepDownLiquidCascadingPopup` 统一调用。普通 Popup 为 25dp 外壳；条目按下述公共紧凑规格与胶囊高亮排布。普通下拉动效对照 NexioSchedule `2daf4c3` 及用户提供的 APK：尺寸进入弹簧 0.77/220、退出 0.85/650；锚点迁移进入 0.77/420，退出 340ms `(0,0,0,1)` 曲线。面板起点覆盖当前值与箭头，外加横向 14dp、纵向 10dp 留白；宽高独立插值并保留过冲，固定画布每边留 14dp 回弹空间和 24dp 阴影外距。当前值与箭头在弹层内按原尺寸移动、淡出，原位置暂时隐藏这两个元素，关闭后交还；设置行标题保持原位。菜单文字独立等比缩放、分段显隐和 0–6dp 瞬态模糊，静止后释放文字 RenderEffect；玻璃在固定画布内采样，轮廓单独变化，材质透明度不乘到文字上。展开后不增加整页遮罩；普通设置行保留按压灰色反馈，首页个性化弹窗通过 `showAnchorPressFeedback = false` 单独关闭。级联二级菜单继续使用其真实父子锚点 Morph。
- 公共 Popup 默认条目为 14sp、中等字重、最小 40dp 高和 7dp 纵向内距；局部调用方可覆盖。选中高亮按行高形成完整胶囊，与面板保持 8dp 内缩。按住后可滑动选择，进入新选项使用与首页菜单相同的 `TextHandleMove` 反馈，松手执行一次，移出取消；悬停父项 350ms 展开后可继续滑入二级选项。菜单尽量按完整内容增高，超过安全区才滚动；可滚动列表关闭滑选，使用正常点击和滚动。Kyant `InteractiveHighlight` 只观察手势，驱动跟手高光和与 LiquidButton 相同的轻微拉伸、位移及松手回弹，不争夺 Miuix 的选择与关闭手势。交互形变放在原动画裁切外，高光在表面裁切内；停止触摸后不保留逐帧任务。
- 个性化面板的地点、教师和文字排布行采用原有开关的 `labelLarge` 字号、字重和行距，常规行高 48dp。文字排布沿用同一下拉控件的局部紧凑样式，菜单条目最小高 44dp、垂直内距 6dp，大字体按内容增高。Popup 触发行点击和展开均不压灰，文字和右侧操作与其他行对齐。
- 级联折叠菜单使用 25dp 外框，沿用锚点冻结、父标题/子项顺序和父子层 Morph。SleepDown 保留根层 Backdrop 防自采样、应用明暗主题、真实 IME 可用窗口和 Overlay 返回优先级；不得在业务页另写一套近似 Popup。公共材质使用 10dp blur + vibrancy、12dp/24dp lens，浅色 `#F2F4F8` 0.28、深色 `#050505` 0.40；删除持续的表面内发光，保留触摸时的 Kyant 跟手光。1dp 高光描边两端白色透明度为浅色 0.66、深色 0.38，距顶部 18% 到 82% 的侧边区段完全淡出，避免亮线延伸至中段。无 Backdrop 时保持相同几何。二级展开保留主菜单缩放，不再压暗主菜单。
- 级联 Popup 的返回处理使用 Overlay 优先级，必须先于 IME 消费：第一次返回收二级菜单，第二次返回收一级菜单，第三次才由页面/系统收键盘。空白处点击不逐层回退，而是第一次同时关闭一、二级菜单，并保持输入焦点与 IME；菜单卸载后的第二次空白点击再交给页面的键盘策略。
- 级联 Popup 的收回位置使用真实触发按钮中心相对最终面板的坐标，包含安全区导致的位置调整；左右边缘只用于选择展开方向，不能替代按钮落点。助理加号菜单展开后与按钮左边缘对齐，模型选单仍按原右侧方式定位。图片及文件选择器在菜单退出完成后打开，源按钮同步交回。
- 助理附件菜单展开后的文字与图标使用面板主题前景色，收回的加号仍使用输入栏前景色；不要把壁纸输入栏的白色直接带进浅色菜单。
- 二级菜单与父菜单同宽，父菜单缩至 95% 退后。二级实测布局就绪后从触发行的圆角轮廓展开，使用阻尼 0.82、响应 0.34s 的弹簧；标题起点与真实条目上下内距对齐。一级在二级展开、停留和收起期间冻结输入，直到二级卸载后恢复；跟手观察暂停，保留已有视觉平滑归位。露出的父层边缘不作为收起入口，收起使用二级标题或系统返回。
- Popup host 与页面 producer 同样采用兄弟层拓扑；Popup 只消费该页面显式传入的采样域。找不到 Backdrop 时按相同几何回退稳定表面，不得跨根层寻找 producer。
- 多课表快速设置不属于 Popup：两种材质共用 Kit 窗口，保留顶部左“取消”／右“完成”、原内容顺序及保存交接；正文独立滚动，日期子窗口共用标准操作区。滑条和开关按用户要求保留各自现行实现。
- 快速设置的所有行使用同一紧凑水平边距；数字输入只预留短数值宽度，学期状态与日期值排在各自标题下方，避免固定 170dp 输入框或长日期挤压标题。当前周仍自动计算，沿用原保存与详细设置交接。
- 原生快速设置顶栏标题按两侧操作按钮之间的实际宽度测量字号，单行居中，不因窗口或字体比例变化自行折行。
- 普通选择器共用 Demo 底部操作区；QuickSheet 课表设置保留左取消／右完成的84×38dp顶部操作，使用紧凑标题与顶部留白，不套用44dp底部确认按钮高度。个性化一级与二级标题按用户要求同为titleMedium，以SemiBold/Medium区分字重；设置项和说明沿用各自排版，同级对齐并保持一致间距。
- 多课表快速设置的“详细设置”先保存当前 QuickSheet 草稿，再通过 `QuickSheetToSettingsDetail` 跨 Activity Morph 打开 `SettingsDetailActivity`。目标窗口在 `super.onCreate` 前切换为透明 Morph 窗口，直接使用实时按钮 bounds 展开；QuickSheet 留在原 Activity 下层，返回后原样恢复。不得再复制或裁切 Bitmap、挂局部 Overlay 或写第二套 Morph。

## 色彩与玻璃前景色

同一表面只能选择一种前景色来源：

| 表面 | 前景色来源 |
| --- | --- |
| 动态壁纸仍清晰可见的玻璃表单 | `sleepDownGlassForegroundColor(config)` |
| 有稳定面板底色的 Alert、QuickSheet、设置页 | `sleepDownPanelForegroundColor(config)` / 对应主题 `LocalContentColor` |
| 主操作 | 固定主色表面 + 白色前景 |
| 破坏性操作 | 破坏性色及其配套表面 |

标题、摘要、字段值、占位文字、图标、箭头和禁用态必须沿同一来源降低 alpha，不能在同一卡片内混用壁纸反色、应用主题色和写死黑白。

AI 教务导入对话采用局部 `AiImportConversationTheme`，字体、字号、字重、行高和明暗主／次／弱文字色集中在 [AiImportTypography.kt](../../app/src/main/java/com/xiaomanjun/sleepdownschedule/feature/importing/progress/AiImportTypography.kt)。正文使用系统字体，执行记录使用等宽字体；普通灰字使用经过对比度校验的不透明角色色。用户气泡使用浅蓝色，深色模式使用深蓝底。公开的模型进度、回复、待回答的问题和错误默认显示，连续执行事件按原顺序就地分组；相邻重复事件只保留一份，旧摘要和步骤仅补充缺失的消息渠道，不再另设“处理详情”。预览只保留课表内容与新建／覆盖操作，移除“课表选项”入口；继续对话使用最新可见结果，各轮旧预览仍可独立导入。仅影响该页，其他页面保持默认外观。模型选单在完整关闭后的下一次打开重新测量当前位置，中途反向打开保留在途弹簧和锚点，源胶囊等待 Popup 完整退出才恢复。

AI 导入状态与普通公开中间段落使用同一 Markdown 渲染，保留加粗和换行。正文 16sp／26sp 主色，状态 13sp／20sp 次色，工具与执行记录 12sp／18sp 等宽弱色；预览元数据维持 14sp，不随状态字号缩小。所有状态、执行组标题和工具文字共用 16dp 标记列 + 8dp 间距。展开标记和工具标记使用矢量图标，箭头随展开旋转；点击反馈先裁剪为胶囊。模型消息按顺序留在对话中，连续执行事件就地分组，运行中的最新组默认展开，结束后默认折叠，保留手动开关。底部只展示尚未入记录的公开片段和任务总计时，显示“正在导入中”，不随工具／网络阶段重置。具体事件规则见 [AI 文件导入](../ai/AI_FILE_IMPORT.md#对话式导入2026-10-08)。

AI 导入输入框复用 `AgentInputLiquidCapsule` 的玻璃交互与凝光原生柔性反馈，按内容自动增高并保留实际 IME 占位。日视图助手收回时，源卡原生材质随隐藏状态一起关闭，完整退出后同帧交还源卡；弹层与源卡使用一致的连续圆角，避免末帧叠加两个材质外壳。

首页课程卡片的地点、课名、教师和其他彩色信息使用相同的不透明同色系字色，以字号区分信息层级。浅色无壁纸时，凝光和液态玻璃都按卡片较深处的实际合成底色计算字色，目标对比度为 7:1。有壁纸且页面使用深色前景时，保留课程色相，取在白底上仍达到 4.5:1 的最亮同色，不再把课程色固定压到低明度；对比度不足时增强软阴影。无壁纸时按实际底色与卡片透明度的混合结果计算零偏移的弥散阴影，液态卡片绘制和文字背景取同一透明度输入。壁纸场景按局部背景采样调整，滑动与转场期间保持阴影稳定。非彩色文字使用页面统一前景色和低透明度软阴影。

浅色无壁纸的课程卡片保留原色相，以高明度和更高饱和度染色；0.6dp 低透明度同色内描边沿实际圆角绘制。凝光模式继续通过 COUI 背景采样材质、轮廓、底部泛光与触摸光渲染，并叠加顶部轻（20%）、底部课程色增强的半透明竖向渐染，不以不透明纯底盖掉凝光材质；彩色与非彩色文字反色继续按卡片较深处合成底色与页面规则计算（彩色目标 7:1）。液态玻璃及关闭高密度材质的回退路径在无壁纸浅色下继续预合成浅底；周视图的独立与智能特殊课程沿原有胶囊或网格轮廓绘制柔和外阴影，液态玻璃的浅色无壁纸特殊时段带用白色至浅灰的中性渐变、细高光和次级时间字色。

有壁纸的凝光课卡使用迁移前的底部染色曲线。顶部为染色滑杆峰值的 20%，底部达到滑杆值。壁纸上的字色对比估算沿用同一曲线。

导入预览使用稳定的主题面板底色，轻混入课程色；课程标题保留课程色并调整至至少 4.5:1 的文字对比度，时间、地点、教师等使用清晰的面板正文色。预览不复用首页壁纸下的浅亮字色与阴影策略。AI 导入将公开的模型进度和执行消息逐条保留在对话中，继续下一轮和恢复历史时保留对应轮次的记录；预览固定在首次产生该课表的轮次后，下一句话在其下继续，继承的相同结果不重复追加。查看旧消息时暂停跟随，通过输入框上方居中的圆形向下箭头返回最新，保留无障碍标签，不显示文字按钮。周视图真实时间标签使用完整时钟字符串并按列宽测量字号；节次投影与编辑器的按节次/自定义显示共用时间精确匹配规则，不改写已保存的原始时间。并列液态 Dock 的加号与导航外缘间距为 12dp，与原生凝光 expansion view 一致；可交互的液态加号点击提供一次轻触反馈，静态返回图不触发。

设置首页保留功能分组、更新状态与实验标记，提供悬浮搜索及导航结果。首页和二级设置的页面、分组、字体、箭头和原生色板采用 COUI；混用的 Material / Miuix 内容槽也映射同一组颜色与字体角色，避免旧表面和正文颜色透入。选项行沿用原有测量和内边距，导航行图标使用 23dp 槽位。功能矢量按[图标替换清单](../reports/2026-11-13-coui-icon-audit.md)应用。返回图标使用 `CouiIcons.Back`。设置导航行和课程编辑选择行共用 12 × 24dp 的 `CouiForwardIndicator`，按所在表面着色并支持 RTL 镜像。液态模式沿用 glass 材质。通用设置保留各组内容、外观预览及即时保存语义；小组件保留预览、添加到桌面、背景编辑与恢复默认等操作。

首页卡片外的日期、周数、天气、表头和时间标记使用 `HomeReadableText`，在壁纸对比度不足时启用更明显的弥散软阴影；保留零偏移和原模糊范围。该强度独立于课程卡片文字，纯色背景不额外叠加文字阴影。

玻璃不可用、Android 12 以下或 `backdrop == null` 时，同一组件负责不透明降级。降级只替换材质，不改变圆角、布局、点击范围和语义。

## Motion 与页面交接

- 同类入口直接复用已经验收的 Morph spec/controller，不重新拼一条“差不多”的轨迹。
- 设计系统组件不持有导航 session、Activity snapshot、打开/关闭 generation 或最终清理句柄。
- Opening/Closing 的临时 clip、模糊和缓存只在运动阶段存在；Open 页面必须是完整、可交互的真实内容。
- 弹窗挂载在完成背景录制后的根 host；producer 与 host 必须是兄弟层，不能只靠 draw-time 排除避免自采样。
- 减少动效时保留空间关系和源/目标语义，不能以无锚点中心淡入替代成熟返回链路。

## IME 与输入区

输入页必须先明确谁拥有键盘位移：Window resize、`imePadding()` 或手动 inset 补偿三者只能有一个最终负责人。

- Activity 使用 `ADJUST_NOTHING` 时，底部输入区可以按 IME inset 手动移动，但要扣除系统已经通过 resize/pan 应用的物理底边位移。
- OEM 可能同时 resize 和 pan，不能只取两者较大值；应以窗口根布局底边的真实移动量判断。
- IME 关闭动画可能先归零 inset、后恢复根布局，隐藏态 baseline 要等待布局稳定后再提交。
- 列表底部 padding 只用于保证最后一项可滚到输入区上方，不再独立补一次 IME 高度。
- 切换附件预览、历史页、窗口尺寸或横竖屏时要重新建立会话基线，不能沿用旧窗口坐标。

## 新页面决策顺序

1. 明确页面任务：设置、内容、沉浸，还是锚定 Morph 详情。
2. 选择既有页面壳和顶栏策略，不在业务文件新建 Backdrop 拓扑。
3. 选择内容节奏；只有真实信息密度不同才覆盖边距或间距。
4. 判断内容应放分组、原地展开、Picker、Alert 还是完整表单。
5. 统一表面内全部前景色来源，并实现同几何的无玻璃降级。
6. 明确保存语义、返回语义和 IME 位移所有者。
7. 验收窄屏、平板/横屏、字体缩放、明暗主题、明暗壁纸和无 Backdrop。
8. 若涉及 Morph，再验收 Opening、Open、Closing、快速返回和真实锚点恢复。

## 允许的差异与禁止的差异

允许：

- 因任务不同选择大标题、紧凑顶栏或沉浸控制层；
- 因信息密度调整内容间距、列数和卡片内部排版；
- 因主次关系选择内联操作、底部操作或顶栏操作；
- 成熟页面保留自己的 Morph 几何和专用视觉细节。

禁止：

- 在业务页面复制一套 Dialog window、QuickSheet material 或无玻璃 fallback；
- 同一表面混用不同前景色来源；
- 为单设备写死安全区或屏幕尺寸；
- 把业务保存、数据库写入或转场 session 放进设计系统；
- 为追求“统一”改写已验收的课程编辑器、首页菜单、个性化面板或跨 Activity Morph。

## 当前迁移状态

- 通用设置、AI 设置和今日助手设置已等价接入 `SleepDownSecondaryPageList(Settings)`；原 16dp 边距、14dp 分组间距和 Dock 底部空间不变。
- 助手记忆、日期和时间选择器已接入 `SleepDownPickerDialog`；凝光使用 Kit 操作区、WheelPicker／CalendarPicker，特殊正文保留业务约束。
