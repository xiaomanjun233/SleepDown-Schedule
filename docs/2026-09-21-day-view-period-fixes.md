# 日视图与作息间隔修复

## 原因与修改

- 课前间隔的分钟选择器允许选择 0，但提交时又被限制为至少 1 分钟，且间隔卡片没有移除按钮。课前与课间统一支持减号移除、拖短或选择 0 分钟；只提前当前作息中同一分段的后续课程，不改变节次结构、其他分段或其他作息。移除课间后显示紧凑的“添加课间”入口，首节开始时间仍可重新创建课前间隔。
- 用户截图中的普通课程误置灰、半宽遮罩来自旧实现。`80e6aae` 已将 `adjustment?.sourceDate == null` 改为先确认调休记录存在，并移除按正文范围绘制的灰色覆盖层。本次沿用该修复，课程灰色直接由材质和文字配色表达，不覆盖正文。
- 日视图时间胶囊复用 `CourseGlassCard` 和 `CourseCardText`，跟随课程的轮廓光、卡片颜色、彩色文字、明暗前景和材质开关，不再叠加旧的半透明实色底。
- 按用户确认，仅日视图对今天已结束的课程置灰，包含两日模式中日期为今天的部分；仍能点开编辑，不将已结束误标为停课。按实际最后节次或自定义时间的结束点判断，其他日期和周视图保持原样。时钟按分钟更新，页面回到前台时立即刷新；调休课程按实际显示日期判断。

## 验证

- `testGithubDebugUnitTest` 定向测试 58 项全部通过，0 失败、0 错误：作息时间线编辑 34、时间线变更 8、日视图结束状态 5、次日预告 4、课程分组 7。通过临时 `tmp/day-period-tests.init.gradle` 选择相关源文件，未运行无关套件；耗时 2 分 19 秒。
- 覆盖 1 分钟课前间隔归零、负时长边界、课间删除后恢复、末节压缩恢复、其他方案与节次编号保持不变，以及课程最后结束点、自定义时间、缺失结束时间、跨日和调休日期。
- 界面材质沿用公共组件，未增加机械样式测试。实机外观、滚轮和拖拽交互仍需现场验收，不能以单元测试代替。
