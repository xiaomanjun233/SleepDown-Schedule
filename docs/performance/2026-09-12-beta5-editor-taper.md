# Beta5 形变、课程轮廓光与网页多行取色

基于 `b22e28a`，处理形变过强、关闭反向、内容不跟随以及末尾轮廓突变的反馈。

- 幅度系数从 0.32 降到 0.16。前 12% 时间平滑建立轻微形变，随后随经过时间近线性减弱，避免在动画中段才达到最大形变、末尾集中恢复。
- 关闭不再反转上、下边缘。宽窄方向始终由打开时的课程位置决定；复制保存后的落点只影响飞行路径，不改变已建立的形变方向。
- 原先非零形变使用自定义连续圆角路径，归零时切到 Kyant RoundedRectangle，两者在端点可能不重合。现在始终从 Kyant 的同一基础轮廓生成形变；采样圆角使用当前密度换算后的半径。
- 外壳路径、表单、标题、字段、图标和课程文字使用同一透视矩阵。对已有内容绘制应用矩阵，不重新测量表单，也不增加整张表单的快照或离屏纹理；稳定时释放临时矩阵。
- 保留上一轮表单生命周期：预载后仍播放逐行进入，关闭立即卸载真实表单，仅外壳与课程回落内容参与退出形变。
- 个性化复用同一形变包络与透视矩阵；只在稳定 Open 阶段挂载表单，避免滑块、开关与外壳运动并发。开关轨道从 64×28dp 改为 52×24dp，滑块从 40×24dp 改为 32×20dp，按压放大从 1.5 调到 1.2；个人设置行仍保持至少 48dp 高度。
- 仅课程卡片启用顶部和两侧的主题色轮廓光。沿实际圆角轮廓绘制三层内侧描边，不增加模糊纹理或 Backdrop 消费者。浅色判断沿用既有玻璃明暗样式（壁纸亮度及首页文字风格）；浅色时主题色混入 14% 黑色、增强颜色覆盖，并将白色轮廓光强度降至 45%、固定白色高光降至 55%。底边保留原渐变分布，浅色时颜色使用 SrcOver，避免加色让浅底继续泛白。
- Shortcut 单独关闭外投影，不影响三点菜单；教务页灵动岛关闭外投影，保留玻璃、轮廓高光和内部材质。

网页多行取色：

- 从当前可见 WebView 顶部 48dp 区域缩采样为 64×24，替代原来的全宽 1px 行。主网页/弹出网页切换后按当前显示对象取色，不采隐藏网页。
- 透明像素按 alpha 加权，RGB 各分为 8 档统计面积。按面积的 1.5 次方提高大色块权重，减轻零散文字/细线影响；所有色块在线性 RGB 中融合，再转回一个 sRGB 主题色。全透明结果不覆盖已有颜色。
- 重用 Bitmap、Canvas、像素数组与调色板累加器；取色最多约每 96ms 一次，连续滚动合并请求而非不断延期。颜色以 160ms 平滑过渡，只在顶部补色层的绘制阶段读取动画值。退出取消回调并释放采样位图，不保存网页像素到文件或日志。
- 保留 Nexio 的普通窗口 WebView 渲染与兼容设置，以及 SleepDown 的渐变遮罩、独立采样域和 Compose 图层隔离；本轮不切换 WebView 模糊算法。
