# Beta5 顶栏衔接、彩色轮廓光与表单开销

基于 `6b48f50`，按用户追加反馈修改。源码提交至 `9258e14`；本记录取代上一轮关于轮廓光压黑、整份表单挂载和 520ms 表单入场的现状描述。

## 课程轮廓光

- 日、周视图共用 `verticalGlassAccent`，两种玻璃明暗风格都直接使用课程颜色，不再向黑色混入 14%。课程轮廓光同时跳过顶部的黑色压暗渐变。
- 顶部/两侧的缓存网格与底部彩色光使用 Screen 提亮混合；顶点颜色与白色画笔仍采用 Modulate 合成，但画笔最终对目标使用 Screen，避免以 SrcOver 把暗颜色叠成黑边。保留细白色玻璃高光，不增加模糊、离屏层或采样。
- 左右羽化宽度缩至顶部宽度的 55%，顶部范围不变。侧边上限由 20dp 变为 11dp，小卡片继续按实际宽高收缩，沿真实圆角裁切。

## 教务页顶栏与网页交界

- 原来的旧遮罩结束位置为 1.14/1.10，实际顶栏在 1.0 处终止时仍有可见残留；填充顶栏的主题色也在 WebView 顶边直接终止。
- 仅教务页的旧渐变模式将既有消费者向下延伸 48dp，遮罩和 tint 在新范围末尾完整归零。使用视觉层的测量扩展，顶栏占位及 WebView 的布局、视口和交互坐标不变。
- 现有多行取色在原 producer 内向网页延伸 28dp 的平滑颜色渐变，不增加 WebView 抓取或模糊 pass。主网页和弹出网页共用该过渡；仍保留原来 WebView 的 Compose 离屏隔离、取色和旧遮罩链路。

## 表单延迟与按需组合

- 代码检查发现 `HorizontalPager.beyondViewportPageCount=1` 会强制准备邻页；正文使用滚动 Column，把屏外输入框、选择器和按钮一并组合。
- 改为 `beyondViewportPageCount=0` 和带稳定 key/contentType 的 LazyColumn，只为当前可见页面、字段及框架必要预取创建 UI。草稿仍由列表和分页上层持有，字段离屏不会丢失已填写的文本、星期、节次或周次；分组、复制和保存规则不变。
- 外壳仍先完成 380ms 的形变，背景保持原来的惯性曲线，配置改为 420ms + 20ms 延迟。两者停稳后挂载真实表单，逐行进入由 520ms 改为 300ms（每行 200ms，间隔 8ms）。
- 配置时序从 600 + 520 = 1120ms 缩为 440 + 300 = 740ms；此数值不包含菜单收回、实际布局或调度耗时，不是实机性能测量。关闭仍立即卸载表单，不引入假表单或截图交接。

## 无界周视图表头

- 顶栏父布局曾只容纳状态栏、66dp 标题栏及 46dp 表头，限制了更高的渐变层；同时 Nexio 的半径从顶部就开始衰减，原有 alpha 遮罩平台参数不能维持模糊强度。
- 父布局与模糊层统一使用覆盖完整表头并留至少 56dp 尾部的高度，适配实际顶部安全区。星期/日期仍在渐变之后绘制，不被模糊。
- 公共渐变入口增加可选 `radiusFadeStart`，默认 0 保持其他原生页面的曲线；无界模式维持完整 7dp 模糊至表头下方 4dp，再连续衰减。主采样与去噪使用相同曲线，采样次数保持 32/12；WebView 继续走旧遮罩分支。
