# 主线：课程轮廓光、明日预告与背景冻结

基于 `b12b8c2`。删除没有独有提交的本地 `codex/sleepdown-for-swu`，保留最新通用开发代码，在 `codex/mainline-preview-performance` 继续开发。GitHub 分支查询没有找到远端 SWU 分支。既有未跟踪 SWU 调查文档未修改。

## 课程显示

- 课程主题色网格取消左右侧光，保留原有顶部 16 段衰减、底部光和真实 Shape 裁切。顶部只需 34 个顶点、32 个三角形，不再生成覆盖整张卡片的二维网格。
- 日视图、两日视图和明日预告统一按完整课程列表分组。旧代码只遍历四个时间段，无法归入配置节次范围的课程会丢失；无节次锚点的自定义时间课程和超出配置分段的普通课程都会受影响。现在保留它们并列入“其他时间”，不修改数据库时间、节次或课程数。普通上午／中午／下午／晚上分组保留原规则。

## 背景冻结的范围和成本

用户要求保留现有模糊与缩放，并避免因冻结引入重建成本。当前选择保留首页原有 Composition、课程节点、玻璃节点和 GPU 场景层，冻结其数据输入和画面；前景编辑器、菜单和弹窗继续运行。

- 移除首页的课程材质卸载、纯色替代帧、分批恢复和恢复淡入状态机。开启／退出弹层不再因这些状态更换课程材质节点。
- 日、周视图的课程编辑器、锚定菜单、个性化及课程快捷菜单复用同一个无缩放背景场景。原来的缩放曲线、模糊半径、模糊档位及 Closing 分辨率交接保留在外层。
- 准备阶段录制真实源卡片隐藏后的背景，之后语义帧不变时只重放该层。再次打开、源控件交接、窗口尺寸或字体密度变化会更新录制标识，避免使用旧视口。恢复时若已经录制新帧，直接重放一次，避免同帧再次遍历整页。
- 不再为打开课程编辑器切换壁纸质量。背景数据引用保持稳定；日视图与助手的分钟时钟、快速编辑摇晃及背景文字的壁纸采样在冻结期间暂停。
- 日卡片点击锚点改为普通引用，位置变化不再写入 Compose 状态。菜单收尾的位移和缩放直接在布局／图层阶段读动画进度。
- 个性化滑块预览恢复实时更新；复制课程落点计算允许新课程进入已有布局，避免阻断保存与返回。关闭后接入最新数据，未清除、回滚或延迟实际数据库写入。

这是对背景输入、已知后台更新源和绘制入口的冻结，并未暂停整个应用的 Recomposer。前景交互、业务协程、系统生命周期仍运行；没有为背景创建第二套 ComposeView、Composition 或 CPU 位图快照。

## 性能证据与验证边界

用户截图来自 OnePlus 13 / Android 16，约 15 张课程卡，报告左右切周和打开课程／弹窗卡顿。截图显示平均约 69.4 FPS、最长帧约 271ms，足以确认掉帧，但没有调用栈或帧归因，不能单凭温度读数判定热降频，也不能据此证明本次修改改善了多少 FPS。

源码发现的重复工作包括背景材质重建、日卡片位置状态更新、缩放期文字采样及菜单动画读值范围。取消左右光减少新页网格创建开销；切周期间背景仍需实时移动，因此不会冻结 Pager，也没有删除相邻页预热。

本机连接设备为 PLJ110（Android 17 / API 37），并非报告中的 OnePlus 13。2026-09-14 已完成正式签名 Release 构建并覆盖安装到该设备，保留应用数据，未自动启动。尚未运行实机帧率测试，不声称达到 120 FPS。
