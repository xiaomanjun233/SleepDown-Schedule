# Beta5 手势与弹窗生命周期回归修复

基于 `3e8c768`。这是上一轮安装反馈后的跟进，历史验证保留在
[编辑器、翻页和材质跟进](2026-09-12-beta5-rendering-followup.md)。

## 手势与弹窗

- 周课程卡片上一轮不消费 down，外层 HomeSchedule 的空白长按 `detectTapGestures` 因而也接收并消费同一次 down，干扰卡片的点击和长按等待。恢复卡片在 Main pass 消费 down；父层空白检测只接受未消费的 down。Pager 仍可观察 down，并在位移超过 slop 后接管滚动。
- Shortcut 优先放在上方；上方放不下则从下方展开，缩放原点改为顶部，位移连接卡片底边。左右列原点、40dp 行高和先收回再执行动作保持不变。
- 编辑器保留固定目标尺寸的预载表单，但去掉 Preparing/Opening/Closing 之间额外的图层录制与回放切换。准备帧观察移到透明内容层外，避免等待 alpha=0 内部不会执行的录制而耗尽准备帧上限。
- 表单的逐行入场在每次 Opening 重置并播放，跨 Opening→Open 保持同一实例；按最新要求，关闭开始立即卸载表单及其采样节点，仅外壳继续形变。收回方向根据实际目标计算，复制后的新位置仍使用既有落点。
- 个性化 Preparing/Opening 不挂载表单。壳体和背景运动结束、呈现一个稳定帧后挂载控件并播放逐行动画；关闭开始立即卸载。

## 外观与采样

- 个性化玻璃滑块由 40×24dp 调为 32×20dp，按下放大从 1.5 倍降至 1.2 倍，端点内缩到 16dp；36dp 触摸轨道、吸附和提交语义保持不变。其它设置页沿用原尺寸。
- 快速编辑角标从课程的真实连续圆角路径截取中心线，再使用 8dp 圆头、圆连接描边生成玻璃轮廓，避免先填充再矩形裁切造成平直端点。角标继续补偿输入区域的 4dp 偏移。
- 中心弹窗的全屏模糊此前使用原分辨率 plain renderer，壳体也未降采样。二者接入既有 0.5 倍宽高的 Backdrop 路线；半径随采样密度换算，文字、着色、遮罩和装饰保持原分辨率。这是代码层面的开销削减，不代表已验证帧率收益。
- WebView 保留 Nexio 的普通窗口硬件渲染，不强制 WebView 硬件纹理。网页路由局部恢复旧的「固定模糊 + 渐变遮罩」；主网页和弹出网页恢复 Compose Offscreen 采样隔离边界，顶栏继续采集独立 web-content producer，保留顶部边缘颜色补偿。原生页面继续使用 Nexio 新渐变模糊和 32 次径向采样。
