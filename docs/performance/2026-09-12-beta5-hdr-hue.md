# Beta5：HDR 保留课程色相、柔化交界及编辑器停用

后续状态：用户反馈卡顿后，HDR 已被移除并改为普通主题色加色光效，见 [后续实现](2026-09-12-beta5-sdr-course-light.md)。下文保留本次实验与交付事实。

基于首版 HDR 的 `451f1e8`。用户追加要求：只提亮上下边缘，期望比率 1.2；HDR 发光/不发光区域交界不能出现断层；打开课程编辑器瞬间停用；提亮各自课程主题色，不发白。

实现提交：`ca75149`。

## 颜色与交界

- 首版用 `1 + courseLinearRgb × (headroom - 1)`，所有通道至少为 1，天然加入了一层白色。现在改为线性 RGB 的三个通道乘同一个比例，将最高通道缩放到 1.2，保留通道比例。黑色保持黑色；没有把缺少的颜色通道补白。
- HDR 使用 Lighten 混合：只提高比已有背景更亮的通道，避免 SrcOver 在浅色壁纸压暗其他颜色，也不依赖 Screen 在白色上无法继续增亮的结果。最终屏幕像素亮度还取决于透明度、背景及系统色调映射，1.2 是请求的 headroom 和源色峰值上限。
- 原 HDR 顶点透明度经 ARGB8 量化，并在卡片外缘直接裁切亮像素。改用无采样的颜色 RuntimeShader，在浮点路径内计算覆盖度：外缘先渐入、向内渐出、左右端逐渐退回普通侧边光；五次平滑曲线在端点的一阶、二阶导数均为零。
- 上下边缘共享一份缓存画笔，不增加玻璃消费者、背景截图、RenderEffect 或离屏层。HDR 不再创建顶点网格；普通三边彩色光仍复用原网格。
- 圆角取实际 RoundedRectangle 或 morph geometry 的半径，先在其内淡出，再沿原 Shape 裁切；不猜测未知 Shape 的半径，未知形状保持普通光效。日/周视图和玻璃明暗风格共用。

## 编辑器生命周期

- `openCourseEditor` 的点击回调先通知 MainActivity 停用 HDR，窗口 headroom 立即设为 1，不等待表单、缓存或外壳动画结束。课程编辑器及背景装饰随后一起走普通光效。
- Preparing、Opening、Open、Closing、Disposing 全程停用，回到 Idle 才恢复 1.2。此期间保留窗口颜色模式与高精度目标，不在动画中更换颜色模式；退出功能或屏幕不支持时仍恢复原窗口参数。
- 背景缓存 key 加入 HDR 活跃状态，防止撤销光效后继续重放上一份 HDR 课表。旧缓存交接期间，headroom=1 也限制其额外亮度。
