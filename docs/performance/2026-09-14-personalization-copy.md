# 个性化即时更新、彩色文字与首页复制

## 个性化与文字

个性化面板之前读取被冻结的 `visualState`，离散配色和开关变化没有进入实时预览路线，选中标记与背景可能保留旧值。现在面板读取最新草稿；课程数据仍使用保留的引用，用户明确更改的个性化配置单独应用到该场景。配置变化会使录制标识失效并更新一帧，背景节点不卸载，原有模糊、缩放和滑块预览继续沿用。

新增“彩色文字”，默认关闭，开关位于个性化面板底部，仅显示标题。日视图、两日视图、周视图及其课程动画中的名称、地点、教师等信息跟随实际卡片主题色，包含多彩分配和单课自定义颜色。根据后续反馈，移除描边和额外阴影绘制，文字加粗并沿用卡片现有的明暗前景选择：深色背景混入白色，浅色背景向深色调整，在保留尽量多主题色的同时进入更清晰的前景亮度区间。颜色按主题色和前景配置缓存，不逐帧读取壁纸像素；这里只使用正常 Text 绘制，未进行所有壁纸局部对比度的实机测量。

开关按课表保存。Room 由 39 升至 40，只增加默认值为 0 的布尔列；同步个性化合并、旧表修复保留字段和备份导出／恢复。BackupFormatV1 版本不变，缺少新字段的旧备份按关闭恢复。

## 复制交互

- 长按课程选择复制，再选择全部上课周或仅当前周，直接回到首页选择位置，不再打开课程编辑器。
- 顶部玻璃胶囊从安全区顶部中央向下弹出，同时向两侧展开，配有 Compose 提示图标和取消按钮。入场适配安全区，不假定某款设备的摄像头尺寸。胶囊随短句内容调整宽高并使用弹簧过渡，冲突统一提示“课程冲突，请换个位置”；表面模糊为 16dp，整个胶囊统一复用 LiquidButton 的形变和高光反馈。叉号仅定义 44dp 的关闭点击识别区，不绘制独立反馈，也不使用默认压暗；按在叉号区域仍驱动整个胶囊。
- 首次点击空位显示占位并震动；再次点击该占位才保存。点击另一个空位会重新选定，不直接保存。超出节次边界或所选周次发生冲突时给出提示。
- 普通课程保留原节次组合的相对间隔；自定义时间课程以目标节次开始时间为新起点，保留精确时长。全部周／单周范围保持既有选择语义，不静默扩展到范围外周次。
- 事务内再次核对当前课表与冲突，避免点击后切换课表或出现新课程导致误写。保存失败保留选定位置供重试；原课程始终保留。
- 保存成功后从原课程位置生成副本，先微微长出，再沿缓动弧线飞往占位。落地复用周视图的压缩回弹及邻近卡片涟漪；副本与持久化卡片只在同一位置交接。既有课程周次合并不会阻断交接。
- 滚动中的占位随网格移动；切周清除旧占位；窗口变化或退后台使旧动画会话失效，迟到的写入回调不会重新拉起旧浮层。

## 删除交互跟进

快速编辑删除入口原本先显示“删除单周课程”，再转到根页面的删除范围弹窗；现移除前一层，只保留“仅本周／全部周次”的范围选择。

删除沿用原数据库事务，写入生效且编辑器／范围弹窗关闭后播放 1.1 秒消散动画。仅临时保留待删除的课程行和已有卡片节点：从上往下以不规则发光边缘侵蚀，生成主题色光粒子向右上方随风飘散；最后一批粒子结束后移除显示。删除失败立即解除保留，切换页面／模式／课表也会解除。单周范围只对对应周的卡片播放动画。

粒子参数与画刷按卡片尺寸缓存，最多每卡 180 个粒子，动画进度只在绘制阶段读取；不生成位图、不逐帧重组课程内容，也不在整张课表上增加模糊层。

Beta6 为飞行粒子增加轻量运动模糊：沿真实曲线采样过去 18ms 的四个位置，按归一化权重合成柔和拖尾。模糊只作用于粒子，不新增整屏 RenderEffect，粒子数量上限和 1.1 秒动画时长不变。
