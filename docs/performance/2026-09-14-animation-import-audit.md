# 2026-09-14 动画排查与导入体验改进

本轮在 `codex/mainline-preview-performance` 上继续开发，不变更已发布的 1.2.6 Beta1 产物。

## 动画范围与依据

| 场景 | 代码发现与处理 |
| --- | --- |
| 左右翻页及纵向滚动 | 初次尝试将坐标改为普通字段并直接 invalidateDraw；Beta2 实机反馈玻璃背景不再随滑动更新，已撤回这一替换。恢复只在绘制阶段观察的坐标 State，保留冻结期通知门控，不改变分辨率、模糊、折射、高光或文字质量。 |
| 首页背景、周视图课程玻璃 | 已冻结数据和场景层，但消费端还可能重新录制相同采样指令。本轮复用同一节点已有的采样层；仅在显式冻结、场景标识及尺寸/密度/字体比例/方向一致时命中。 |
| 课程编辑器 Morph | 宿主直接读取动画进度，并在组合阶段生成尺寸、圆角和源卡透明度。本轮将这些读取延后到布局、轮廓及图层阶段；模糊插值保留在局部材质组件中。 |
| 首页菜单 → 添加课程、手动导入、教务导入 | 保留已有固定尺寸内容录制，在运动且录制完成后暂停内部玻璃的全局坐标通知；稳定后恢复交互。窗口或密度变化使录制失效。 |
| 跨 Activity 菜单目的页及 Liquid 路线 | 将按帧传入 Float 改为延迟读取进度，几何和透明度使用派生状态。条件组合只响应源内容显示/隐藏、全屏终点等离散边界。已有录制内容运动期间暂停玻璃坐标刷新。 |
| 个性化 | 当前光晕与渐进背景通道已关闭，却仍可能计算两套各 512 个样本的包络。本轮按实际启用情况跳过计算，保留已生效的外壳与模糊动画。 |
| 详情返回、中心弹窗、快捷菜单、复制与删除 | 已有图层阶段读取、固定模糊层或绘制阶段驱动；本轮保留这些路线，没有为统一形式重新实现。 |

沿用原有 GraphicsLayer 和材质节点；不新增 CPU 截图，不卸载首页 Composition，不创建分批恢复队列。采样复用只在首页冻结域显式启用，运动中的前景外壳仍跟踪采样位置。模型、效果、环境、节点生命周期变化会使缓存失效。

动态圆角必须同时驱动裁剪、折射和高光，且随采样密度等比例变化；固定尺寸下也要响应圆角状态更新。

本报告记录代码路径与验证结果，不将减少重组/录制等同于已经测得的 FPS 提升；本轮尚未进行同设备同场景的帧时间对照。

## 同轮功能

- WakeUp 时间表按实际开始时间排序，将严格重叠的连续区间归并为最早开始、最晚结束，映射每门课的原节次。首尾相接不归并；自定义课程保留精确时间。仍经过导入预览确认，不直接写入数据库；其他教务适配器保留原校验。
- 例如 08:00–08:50、08:40–09:30、09:20–10:00 归并成 08:00–10:00；紧随的 10:00–10:45 单独保留。
- 时间选择器完整 0–59 分钟范围启用循环，59 后接 0；有开始/结束边界限制的分钟范围仍受约束。
- 删除按版本自动弹出的无界模式介绍，保留用户既有周视图偏好。
- 周视图“第 X 周”右侧增加天气小图标和气温，复用今日助手的天气缓存、设置与定位授权，前台更新，冻结时暂停。无可用天气时隐藏。
- AI 导入在独立圆角区域展示服务返回的流式思考内容，约 10 次/秒限频，只展示最近 4,000 字的阅读窗口；完整返回仍用于原有解析与历史。任务和修复轮次隔离迟到回调，支持 Chat Completions 与 Responses 的已有思考字段。
- 当前结果与历史修改的模型摘要默认折叠。没有思考字段的服务显示等待提示，不合成模型思考。
- 复制选点按可落入节次的卡片中心与点击点的距离选择目标，包含自定义时长的实际卡片高度；点击已有占位仍直接确认。先确定最近目标，再检查冲突，不自动绕过冲突去复制到别处。
