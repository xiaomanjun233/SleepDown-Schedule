# SleepDown 课程表 2.0.2

## 教务导入

- 新增与 Nexio 课程表共用的 AI 教务适配仓库。仓库脚本标有「AI 生成」，脚本由用户提供并上传，由SleepDown 课程表和 Nexio 课程表的内置AI生成。
- AI 教务脚本验证通过后直接打开课表预览。创建或覆盖课表成功后，自动保存并上传本次验证通过的脚本。
- 教务导入适配器列表现在可快速切换 GitHub 和 Gitee 仓库源。
- 修复部分学校登录办事大厅后提示「未经授权的访问」的问题。升级后，首次手动导入可能需要重新登录。

## 今日助理与免费 AI

- 修复AI助理无法正确读取上下文的问题，连续补充课程名称、时间或地点时，可以接着已有信息处理。
- 为每日免费 AI 的对话与导入引入每日限额，可在 AI 设置中查看剩余额度，额度每天重置，导入结果通过校验后才计次，2.0.2发布后，所有旧版本将停止免费AI服务。

## 使用体验

- 修复导入页不能向上翻阅的问题，停留在底部时会跟随最新进度，向上翻阅时保留当前阅读位置。
