# SleepDown Schedule 2.0

这次更新重做了课表作息、导入和设置。一个课表可以同时使用多套作息，常规导入、教务导入和导入历史也集中到了同一个入口。

## 课表与作息

- 同一课表可为不同校区、教学楼或课程指定作息，也可为课程设置独立时间。周视图按实际上课时间显示，连堂和自定义课时保留原始安排。
- 新增日期作息规则，可按日期切换夏季、冬季等作息。本课表作息只影响当前课表，公共作息修改会同步到引用它的课表。
- 新增特殊课程管理。午休等固定时段可按节次、课时或自定义时间设置，支持独立显示和智能显示。
- 新增周日作为一周开始的选项，并同步到调休、课程复制、小组件、AI 周次和日历导出。
- 非本周课程只预告之后仍有安排的课程。单双周按实际周次判断，当前周的课程优先显示。
- 详细设置集中整理本课表作息、节次、调休和特殊课程。快速设置同步已保存的修改，并保留面板中正在编辑的内容。

## 导入与教务

- 首页加号打开统一导入页。常规导入与教务导入可滑动切换，教务列表保留悬浮搜索。
- 粘贴可识别的课表口令直接预览。选择文件后进入解析页，支持本地校验的 JSON 和 ICS 可直接预览，其他资料可交给 AI 解析。
- 常规和 AI 导入共用历史记录，可滑动清除单条记录。已导入的课表可从历史详情交给 AI 继续修改，应用课表前会先预览并确认。
- 教务、WakeUp、拾光、AI 和口令导入保留学校作息、自定义时间和组合课程安排。提醒、勿扰、小组件和日历按同一套时间规则显示。
- 教务登录支持账号、学号和密码自动填充。手动导入和自动刷新使用同一套会话恢复方式，刷新可重新查看曾忽略的变更。
- 改善教务列表较长分组的点击与滚动，收起的教务进度胶囊使用纯黑底。

## 界面与交互

- 凝光模式采用 COUI-Kit 的底栏、按钮、开关、滑条、弹窗和选择器。液态玻璃继续提供独立材质。
- 改善浅色无壁纸时课程文字和卡片的对比度，调整凝光课程渐变和两种模式的特殊课程显示。
- 横屏和平板保留双栏设置。顶部标签可滑选，二级标题、背景与系统安全区随窗口尺寸适配。
- 支持金标联盟无缝动画的设备可使用系统开合效果。完善课程、设置和导入的圆角、返回落点及源按钮衔接。
- 关于应用重新整理开发者、仓库和项目致谢。软件更新页支持查看本版更新说明，自动更新设置和历史日志集中在右上角菜单。

## AI、提醒与数据

- 改善 ChatGPT 账号接入的模型图片能力识别、课表查询和本地工具反馈。DeepSeek 与 MiMo 可刷新模型列表。
- 今日助理卡使用更轻的模糊，进度条按流体云样式显示扫光。
- 自动静音或震动时可一并控制媒体音量，并在下课后恢复。课中手动调整的音量会保留。
- 切换应用图标后，同步刷新课程通知和小米超级岛的图标。
- 升级前保留数据库副本。旧课表、口令和备份可继续使用，异常时间会提示确认，备份可保留新的作息关系。
