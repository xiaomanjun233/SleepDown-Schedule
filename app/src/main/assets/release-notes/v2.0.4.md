# SleepDown 课程表 2.0.4

## 重叠课程与自由排课

- 新增周课表重叠课程堆叠展示与展开预览。同一时段存在多门课程时，顶层卡片右上角会显示「N门」角标；点击可平滑展开带时间轴的重叠课程卡片页，支持横向翻阅并直接点击进入课程编辑，退出编辑后先返回重叠页。
- 取消原有课程冲突提示与拦截限制。周视图编辑状态下，拖动移动或拉伸课程均可直接与已有课程叠放，并加入了落入下层与前景卡片回弹的交互动效。

## 卡片质感与显示优化

- 优化浅色壁纸下课程卡片彩色文字的明度，在保持可读性的同时让色相更通透。
- 修复无壁纸浅色模式下凝光课程卡片缺少背景质感与竖向渐染的问题，同时保留原有文字反色效果。

- 修复 AI 快捷切换面板中无法显示和切换用户自添加模型的问题。
