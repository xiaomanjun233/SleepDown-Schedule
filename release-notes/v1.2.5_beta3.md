# SleepDown 课程表 1.2.5 Beta3

这是测试版，建议升级前导出备份。与当前新版正式包及 Beta2 使用相同包名和签名，可覆盖安装。本版 versionCode 保持 31，通过版本名称中的 Beta 序号检测更新。

从 Beta2 更新：进入「通用设置 → 系统行为」，开启「接收 Beta 版更新」，然后手动检查更新。关闭此开关只接收正式版；同版本正式版发布后也能收到更新提示。

## 本次修复

- 实时活动图标跟随所选简约／看板娘风格及深浅色，切换时更新已有实时活动。
- 系统安装列表的应用图标固定使用看板娘风格。

## 本轮测试版累计更新

- 优化课程卡背景处理、周视图滑动和弹窗动画。
- 提供简约与看板娘两套图标，各有深浅色样式，调整裁切与留白。
- 新增 Beta 更新开关，修复同版本正式版无法覆盖 Beta 更新提示的问题。
- 调整深色居中弹窗按钮透明度。
- 改善 MiMo 与 DeepSeek 兼容性，托管模型继续使用管理平台下发配置。
- 修复今日助手无法清空课程备注，改善部分接口的回复解析。

说明：系统通知区域的图标呈现仍取决于系统样式。部分用户反馈的“未知回复”尚待完整错误信息进一步定位。
