# SleepDown Schedule 1.2.7_beta3

- 新增独立作息管理页面，可在课表详细设置中进入。多个课表可共用同一套作息，原有相同作息自动归并，支持新建、编辑、复制和删除。
- 切换作息时可选择按原节次或按实际时间对齐，并预览受影响的课程。目标节数不足时保留超出部分，切回原作息后可恢复；完全无法匹配的普通课程仍可在课程列表中找到。
- 切换作息不会覆盖课程自带的上课时间，整门和逐节自定义时间都可保留；首页、课程详情、小组件和提醒跟随当前安排。
- 课表详细设置中编辑作息仅影响当前课表；在作息管理中修改共用方案前，会提示受影响的课表。导入、分享及备份恢复保留课程时间与作息关系。
- 新增上课自动勿扰和静音／震动，可设置提前开启与延后恢复，整门课程期间持续生效，包含课内休息；完善开关动画与权限引导。
- 优化作息管理的卡片和操作按钮，调整复制图标与新增按钮；作息对齐选项和教务工具选择弹窗统一样式，内容过长时可在弹窗内滚动。
- 调整课程卡片滑动时的玻璃绘制和位置更新，减少重复计算。
- 修复切换作息后，AI 删除部分节次可能改写剩余课程原来的上课时间、导致切回后消失的问题；按指定周删除和只修改课程名称等信息也会保留原始安排。

本版为预发布版本，版本号为 `1.2.7_beta3`，沿用本轮 Beta 的 `versionCode=34`。附带课程组件为 `6.0.18`。
