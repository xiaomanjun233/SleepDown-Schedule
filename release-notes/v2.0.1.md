# SleepDown 课程表 2.0.1

本版为 `2.0` 的问题修复版本（`versionCode 37`），可直接覆盖升级。

## 问题修复

- 修复部分 Android 12 设备打开欢迎页及透明材质按钮时的闪退问题。
- 修复液态玻璃模式下无法打开作息编辑弹窗的问题。
- 优化多作息与自定义时间识别：自动以多数课程使用的作息为基准，仅保留真实差异课程的自定义时间，并在作息设置中新增「按多数课程整理基准作息」。
- 完善按日期生效的多作息在视图与提醒中的同步，周视图仅在特殊时间课程课前至下课期间将左侧对应节次临时切换为实际时间并标黄，课后自动恢复，课程提醒始终按真实时间触发。
