# SleepDown 课程表 2.0

以下是从 1.2.7 升级到 2.0 的改动。

## 全新界面与凝光视效

- 全面重构二级界面。课表设置、课程管理、通知、小组件、AI 设置与备份恢复等页面统一采用 COUI 顶栏、分组列表和操作按钮。设置首页保留悬浮搜索，弹窗、菜单和滚轮选择器也采用一致的布局与交互。
- 凝光视效扩展到各品牌的 Android 14 及以上手机和平板，覆盖底栏、按钮、开关、滑条、分段控件与课程卡片。可在「通用设置 → 视效模式」切换，较旧系统自动使用液态玻璃。
- 新增 2.0 欢迎动画，点「继续」直接展开课表。可在「软件更新 → 查看亮点功能」重播。
- 重新设计横屏和平板的侧栏和顶部标签。侧栏可收展，标签可滑动切换，设置与导入按窗口宽度安排单栏或双栏。
- GitHub 版在兼容设备上支持金标联盟无缝动画。
- 重做关于应用、软件更新和捐赠页。检查到新版本会直接展开更新说明，下载时在底部显示进度。可按版本展开查看历史日志。

## 课表、作息与学期

- 单张课表可设置常规作息及多套按日期生效的作息。可跟随向导设置时段、节数和课间，再沿时间轴编辑，也可从其他课表整套复制分段、常规作息和日期规则。
- 支持「开启新学期」。选择开学日期即可沿用原课表设置和作息创建空课表，之前的课程留在原课表中。
- 周视图按实际时刻摆放自定义时间与连堂课程，并在需要时标出起止时间。当日遇到临时课时，时间轴显示对应的实际时刻，正在进行的节次以黄色标记。
- 新增特殊课程管理。午休等固定时段可按节次、课时或自定义时间安排，支持有效周次、地点和备注，可选独立显示或智能显示。
- 支持以周日为一周的起点，调休、课程复制、小组件、AI 查询与日历导出同步采用这一设置。填写开学日期后自动推算教学周，非本周课程只预告之后仍有安排的课程。
- 重做调休编辑和节假日导入预览，可选择应用停课或补课日期，手动调整确认后立即保存。

## 首页与课程管理

- 日视图可一键回到今天，周视图可一键回到本周。设置壁纸时根据日期、星期和节次文字所在的区域确定首页配色，课卡文字沿用整页深浅，并用局部软阴影提高可读性。
- 点周视图的空白格可从当前位置添加课程，自动带入星期、节次和周次。优化长按快捷操作、单次课程拖动、卡片拉伸与跨周移动时的反馈。
- 课程管理改用便签式卡片，直接显示教师、地点和上课安排。可长按多选删除课程，也可在详情内侧滑删除单条安排。
- 改善个性化弹窗、课程编辑和日周切换的动画与滚动。凝光和液态玻璃共用壁纸采样，减少切页与拖动时的重复绘制。
- 快速设置同步详细设置中已经保存的修改，并保留正在编辑的内容。

## 导入、教务与分享

- 首页加号进入统一导入页，可滑动切换常规导入和教务导入。教务列表支持悬浮搜索与字母索引。
- 粘贴 SleepDown、WakeUp 或星链口令即可解析预览。课表 JSON 和 ICS 支持在本地解析预览，其他材料可交给 AI 识别。
- 完善拾光、教务、WakeUp、AI 和口令导入的时间兼容。其他校区或教学楼的实际铃声可保留为课程自定义时刻，原始节次和周次随课表导入。
- 教务登录支持账号、学号和密码自动填充，手动导入与自动刷新可共用登录会话。遇到会话更新时更容易继续刷新，也能重新核对之前忽略的课表差异。
- 导入历史显示日期和来源，支持侧滑删除与长按多选。可在历史详情让 AI 继续修改课表，预览确认后应用。
- 新增云端短口令分享，接收方粘贴后即可预览课表。也可直接分享 JSON 或 ICS 文件。

## AI 助理与文件处理

- 今日视图的助理也能上传文件。AI 可处理同批多张图片或多个文件，按页读取 PDF 或查看材料细节，解析结果统一进入课表预览。
- AI 处理期间可补充要求，引导当前任务或排队等下一轮。可在输入框旁编辑或删除待处理的消息和附件，进度和结果在对话内查看。
- AI 教务导入可以读取当前教务页及接口线索并校验提取结果。成功运行的适配脚本可在预览页确认后保存到本机，之后访问相同教务地址时可复用。
- 改善 ChatGPT 账号的图片能力识别、课表查询与工具结果提示。DeepSeek 和 MiMo 可刷新官方模型列表，自定义接口可维护自己的模型列表。
- 今日助理的展开和收回更连贯，处理进度使用带扫光的进度条。助理可提出对特殊课程的修改，确认后保存。

## 问题反馈

- 「设置 → 问题反馈」可提交问题或功能建议，按类别、处理状态筛选和搜索，点进详情查看内容和处理进度。自己的反馈可在详情或从列表长按选中后删除。
- 反馈由管理员发布后公开原文。可选填联系方式，仅本人和管理员可见。

## 提醒、小组件与数据

- 课程提醒、实时活动、自动勿扰、小组件和日历导出按课程实际时间工作，日期作息会同步参与排程。
- 上课自动静音或震动时可一并控制媒体音量，下课恢复，并保留课中手动调整的音量。
- 紧凑的 2×2、4×2 小组件按可用高度和系统字号排版，让第二门课程更容易完整显示。
- 厂商通知的使用教程与诊断集中在面板内。切换应用图标后，课程通知和小米超级岛的图标会同步更新。
- 备份与恢复用页签说明可备份的内容。备份支持保存日期作息和课程自定义时间，升级前保留数据库副本，旧版课表、口令及备份仍可读取。
- 完善应用内检查更新，正确识别正式版、Beta 和修订版本。
