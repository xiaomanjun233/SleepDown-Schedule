# SleepDown 课程表 1.2.5 Beta4

这是测试版，建议升级前导出备份。与新版正式包及 Beta3 使用相同包名和签名，可直接覆盖安装并保留数据。本版 versionCode 保持 31，通过版本名称中的 Beta 序号检测更新。

接收测试版更新：进入「通用设置 → 系统行为」，开启「接收 Beta 版更新」，然后手动检查更新。旧包名的 1.1.5 用户仍需先导出 `.sleepdown` 备份，再安装新版并恢复。

## 首页课程编辑

- 长按课程卡可快速进入编辑、复制课程或移除；长按后继续拖动，可直接移动课程。
- 复制时可选单周或所有上课周，重新选择时间后保存副本；移除和编辑模式删除键均先询问仅本周还是全部。
- 快捷菜单采用 40dp 行高，按压时显示胶囊反馈，移除图标标红；仅中间一列从正上方展开，其余按所在位置从左侧或右侧展开。
- 缩放角标保留贴合课程卡圆角的玻璃形状，笔画加粗、缩短并圆润处理；修正末行测量限制，加大底部安全区。
- 复制课程编辑器补齐居中展开、收回动画和背景模糊，个性化弹窗内容逐行进入。

## 小组件与显示修复

- 小组件及支持的动态预览随所选图标风格更新。
- 小组件设置新增「添加到桌面」，与「自定义背景」并排；补齐今日课程 4×2 的桌面添加预览尺寸。
- 节次表以外的自定义时间课程显示在「其他时间」；不连续节次按各自连续时段提醒，避免提醒覆盖和倒计时起点错误。
- 减少周视图滑动时重复布局和不可见网格的开销，继续保留玻璃、折射、轮廓光和阴影效果。

已完成签名 Release 构建验证。120Hz 流畅度、4×2 桌面预览以及本次角标和安全区调整的最终实机效果尚未完成复测，欢迎反馈。
