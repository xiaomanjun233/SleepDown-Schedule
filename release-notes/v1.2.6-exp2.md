# SleepDown Schedule 1.2.6 exp2

本次实验版修复 ColorOS 课程流体云在删除测试课程或清空当天课程后仍读取旧数据的问题。

## 修复内容

- 课程组件现在会把“当天没有课程”作为有效结果，不再错误回退到上一份课程快照。
- SleepDown 修改、删除课程或结束测试后，会先清除组件中的旧快照，再由组件主动通知 ColorOS 重新读取。
- 点击红色“删除测试课程”后不再需要使用 ADB 手动清理组件；真实课表修改也沿用同一刷新链路。
- 课程组件升级至 `6.0.16`。旧组件会显示需要更新，避免继续使用存在缓存问题的 `6.0.15`。
- 向荣耀 MagicOS 设备开放实验入口、组件下载和主动刷新。YOYO 课程小组件可与 SleepDown 实时活动同时使用；YOYO 是否还会校验组件签名或应用特征，需要以真机结果为准。

## 使用说明

1. 覆盖安装 `SleepDown-Schedule_v1.2.6-exp2.apk`。
2. 在“设置 → 课程提醒与实时活动 → 通知样式”中选择“流体云”。
3. 按页面提示下载并覆盖安装新的课程组件。
4. 点击“测试流体云”；测试课程约 21～22 分钟后开始，进入课前 20 分钟范围后等待系统显示。
5. 再次点击红色“删除测试课程”可立即移除测试数据并请求系统刷新。

实验功能面向 ColorOS，并向荣耀 MagicOS 开放真机测试。本 Release 为预发布版本，不替换正式版；首次进入实验版仍需手动下载安装，安装后可在设置中选择后续更新渠道。

## 安装包

- `SleepDown-Schedule_v1.2.6-exp2.apk`：SleepDown 实验版。
- `SleepDown-ColorOS-Course-Component.apk`：ColorOS 课程组件 `6.0.16`。
