# SleepDown 课程表 1.2.5

让课程安排更随手，让每一次操作都有回应。

**调整课程，在课表上轻松完成**

- 长按课程即可打开快捷菜单，编辑单节课、进入快速编辑模式、复制或移除，都更顺手。继续拖动即可移动课程，调整时长的操作也更加清晰。
- 全新课程复制体验：选择本周或全部上课周后，直接回到课表选择目标位置，先预览，再点一次确认。顶部玻璃提示胶囊随操作展开，遇到课程冲突时及时提醒；确认后，课程副本从原位置飞向新位置，以回弹与涟漪落地。
- 删除也有了新的告别方式：课程从上到下化为光粒子，随风飘散。删除范围只需确认一次，修复快速编辑时重复弹窗的问题。

**课表配色，更有自己的风格**

- 新增「彩色文字」，让课程文字跟随卡片主题色，并根据明暗调整亮度、加粗显示，兼顾配色与阅读。切换课程颜色即时呈现，减少等待。
- 提供「简约」「看板娘」两套应用图标及深浅色样式，小组件与实时活动中的图标也可跟随所选风格。
- 调整课程卡片光效，去除左右两侧的轮廓光；优化无界模式顶栏的模糊过渡，减少对首行课程的遮挡，让课表更清爽。

**滑动与展开，更轻快自然**

- 持续优化周视图翻页、课程编辑与弹窗开合，保留熟悉的玻璃模糊和背景缩放，减少动画中的卡顿。
- 优化课程编辑和个性化面板的展开节奏，减少等待感；移动、调整课程后的落地反馈更加及时。修复部分课程点击、长按无响应，以及屏幕边缘快捷菜单展开位置不合适的问题。

**从明日安排到上课提醒，都更周到**

- 修复今日助手「明日安排」遗漏课程的问题，普通节次和自定义时间课程都能完整呈现。
- 优化上课、课间与课程结束时的通知刷新，分钟提示更新更及时，并改善 ColorOS 下的显示兼容性。修复夜间跨天时实时活动预览立即消失的问题。
- 不连续的上课节次按实际连续时段分别提醒；节次表以外的自定义时间课程归入「其他时间」，特殊安排也能清楚查看。
- 改善今日助手对部分模型的兼容性与回复显示，修复无法清空课程备注的问题。

**导入、桌面与更新，少一点折腾**

- 完善教务网页的「手机版 / 电脑版」切换，改善部分门户页面显示不全、登录弹窗被裁切的问题，网页与顶部工具栏的衔接也更自然。
- 小组件设置新增「添加到桌面」，选好样式即可添加；修复今日课程 4×2 小组件的添加预览尺寸。
- 新增「接收 Beta 版更新」开关：默认接收正式版，也可以主动体验新功能；使用测试版时，同版本正式版发布后也能正常收到更新提示。

感谢每一位参与测试、提出建议的你。1.2.5 正式版，欢迎更新。
